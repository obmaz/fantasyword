## 변경 범위

- `styles/` 20개 파일을 `base/`, `screens/`, `theme/`로 나누고 HTML의 기존 순서·CSS 상대 이미지 경로를 유지했다.
- `images/battle_mode/`를 `images/battle/`, 몬스터 파일명을 kebab-case로 정리하고 JS 참조를 갱신했다.
- 소스·HTML·테스트의 직접 참조와 아이템/몬스터/효과의 동적 경로를 검토해 미사용 WebP 11개(397,476 bytes)를 제거했다.
- 전체 메뉴 원본(255,766 bytes)을 런타임에서 `docs/design/approved-lobby.webp`로 옮겼다. 초기 길드 시안도 같은 참고 폴더로 모았다.
- 참조 없는 keyframes 12개를 제거했다. 사용 중인 공격·피격·타이머·전환·reduced motion은 유지했다.
- `.editorconfig`로 편집기 설정을 맞추고 Node 데이터 도구의 표준 모듈 이름을 `node:` 형식으로 통일했다.
- README·현행 사양·아키텍처·디자인 안내를 갱신하고 `AGENTS.md`, 사용자 요구사항, 작업 인계를 작성했다.
- 오래된 디자인/프롬프트/리뷰는 `docs/archive/`로 옮겨 현행 사양과 구분했다.
- 개발 문서 로컬 링크 검사를 `npm run check`에 추가했다. 배포에 개발 문서/시안이 들어가지 않게 기존 빌드 정책을 유지했다.

배포 이미지에서 제외한 합계는 653,242 bytes(약 638 KiB)다. 원본은 Git 이력으로 복원할 수 있다.
실제 참조가 남은 기존 재질은 CSS를 전면 통합하기 전까지 보존한다.

장착/보상·퀘스트·음성·문제 전환·저장소 로직은 이번 정리에서 변경하지 않는다.
CSS를 이동하더라도 적용 순서와 이미지 주소를 유지해야 하므로 같은 화면의 전후 브라우저 이미지를 비교한다.

## 검증 기록

- `npm run check`: 회귀 테스트 **126개 통과**, 실패/스킵 0. strict 타입·JavaScript 문법·등록/에셋·책임 경계·Prettier 통과.
- 개발 문서 11개의 로컬 링크 검사 통과.
- `npm run build`: **182개 런타임 파일**. manifest의 SHA-256 일치, 문서·시안·삭제 에셋 제외 확인.
- 390×844, 320×427, 768×1024, 844×390에서 로비·상점·장비·통계·설정·배틀 선택·연습·배틀·복수 목록 **36개 화면 전후 비교** 통과.
- 34개 화면은 PNG 바이트까지 일치했다. 큰 화면/가로 뷰포트의 배틀 2개는 렌더링 가장자리에서만 각각 116/38픽셀 차이가 있었고 배치·글자·그림은 유지됐다.
- 모든 화면의 가로 넘침과 전체화면 버튼 경계 검사 통과. 브라우저 런타임 오류/로컬 에셋 404 없음.
- 390×844/320×427에서 무기별 그림·모션/타깃 경계·reduced motion, 실제 정답 채점·주/보조 속성·800ms 문제 전환·방패 재시도·나가기 효과 취소 확인.
- 이동한 CSS 19개는 이미지 상대 경로/결과 주석 외 내용 일치. 애니메이션 파일은 미사용 규칙만 제거했고 전체 stylesheet 로드 순서 동일.

CI와 실제 배포 상태는 커밋 후 GitHub Actions와 공개 사이트에서 별도로 확인한다. 이 기록의 로컬 빌드는 배포 완료를 대신하지 않는다.
