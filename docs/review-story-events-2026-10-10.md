# 스토리 이벤트 확장 코드 재검토

검토 범위는 사자성어 데이터와 출제, 스토리 선택/Day/지도 연결/초기화, 암시장 유물, 야바위 세션·렌더러·공통 UI의 변경 코드다.

| 우선순위 | 발견한 문제                                                                            | 수정과 근거                                                                                                                     |
| -------- | -------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| P1       | 도박장 보상 저장 후 진행 저장 실패 시 재시도에서 중복 지급하거나 완료로 표시할 수 있음 | 지급 이벤트를 골드와 함께 저장하고 진행 저장 성공 후에만 완료한다. 저장 실패/재시도에서 한 번만 지급하는 테스트 통과            |
| P2       | 비전투 연결을 단순 제거하면 일부 지점의 다음 길이 끊어짐                               | 허용되는 가장 가까운 지점으로 연결하고 진입로도 보완한다. 기본 지도 및 재배치 100개의 비전투 연속 금지·출구·전체 진입 검사 통과 |
| P2       | 이전 판 또는 다른 단어장의 야바위 콜백이 새 판에 영향을 줄 수 있음                     | 세션 세대와 단어장/진행 검사를 추가했다. 이전 시작·선택·타이머·지급 콜백 차단 테스트 통과                                       |
| P2       | 브라우저 타이머를 주입 객체의 메서드로 호출하면 Illegal invocation으로 시작 실패       | 타이머 함수를 분리해 호출한다. 실제 Chromium에서 시작과 일곱 번의 이동 확인                                                     |
| P2       | 사자성어가 영어 통계·복수·복습 풀에 섞이거나 테스트가 실제 골드를 변경함               | 별도 데이터·출제 규칙을 주입하고 영어 기록을 건너뛴다. 네 난이도의 정답/오답과 99골드 보존 검사 통과                            |
| P2       | 유물 힌트·재도전이 늘어도 투구/방패가 없으면 조작이 안 보임                            | 실제 최대 횟수로 조작을 표시하고 유물 아이콘을 사용한다                                                                         |
| P3       | 야바위에 공통 상단 배치와 숫자 키 이미지가 적용되지 않음                               | 기존 공통 헤더와 이미지 키 선택자에 추가하고 선택 완료를 보기 아래로 배치했다                                                   |

`npm run check`는 247개 테스트, 실패·스킵 0개로 통과했다. 정적 빌드는 227개 런타임 파일을 만든다. 390×844, 320×427, 768×1024, 844×390의 실제 브라우저에서 로비 테스트 버튼·사자성어·컵 이동/2배·지도/초기화·화면 넘침을 확인했다. 사자성어 120개의 표제어는 국립국어원 표준국어대사전과 대조하고 상세 항목 링크를 저장했다. 뜻은 게임용으로 간략히 편집했으며 난이도는 공식 사전 분류가 아니다.

도박장은 보유 골드를 베팅하지 않는 체험이며 0/10/20골드만 지급한다. 메인 야바위는 실제 지급 없는 테스트 점수다. 컵 부품은 벡터 기반 시제품이고 나머지는 기존 생성 이미지 UI를 재사용한다. 저장 묶음은 기존 저장 경계와 동일하게 브라우저 강제 종료 또는 롤백 자체가 차단된 환경까지 보장하지 않는다.
