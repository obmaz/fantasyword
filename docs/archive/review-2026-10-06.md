# 전체 코드 리뷰 및 구조 개선 — 2026-10-06

초기 개발 단계의 리뷰 기록. 당시의 커밋 식별자는 새 저장소에 보존하지 않는다.
HTML, 전체 런타임 JavaScript, CSS, 3개 단어장,
에셋 참조, 데이터 관리 도구, 테스트, 저장 데이터 호환성과 커밋 메타데이터를 검토했다.

## 판단

서버가 필요 없는 작은 단어 학습 게임에는 현재 정적 웹 구조가 적합하다.
하지만 기존 구조는 전역 이름과 스크립트 순서에 의존하며, 화면마다 히스토리와
레이어를 제어하고 일부 기능이 `helpers`/저장소 폴더에 섞여 있어 수정 영향 범위가 컸다.
이번에는 동작을 유지하면서 책임을 나누고 검증 경로를 추가했다.

## 구조·컨벤션 수정

- 저장소만 `scripts/core/`, 상점·인벤토리·통계·설정은 `features/`로 분리했다.
- 배열 기반 오답 생성과 셔플은 `domain/questions.js`에서 공유한다. 인쇄가 전투 상태에 의존하지 않는다.
- 인쇄 생성은 `features/worksheet.js`로 분리하고 좌우 열의 동일한 렌더링을 통합했다.
- 발음, 스토리 조회, 몬스터 이미지 선택을 각 기능으로 옮겼다. 공통 helper에는 HTML 이스케이프만 남겼다.
- 모달 생명주기는 `modal-manager`에 모았으며 이미지 좌표 계산 코드는 후속 개선에서 제거했다.
- HTML의 긴 인라인 스크립트와 MutationObserver 상태 추적을 없앴다. 뒤로 가기/히스토리는 `navigation.js`만 소유한다.
- 모달은 `<dialog>.showModal()`의 top layer를 사용한다. 배경 입력 차단·포커스와 Escape를 관리하고, 종료 타이머는 재열기 시 취소한다.
- 설정의 하위 화면은 하나의 설정 dialog 안에서 전환한다. 별도의 큰 z-index를 붙이지 않는다.
- 제목/게임/일반 오버레이/알림 레이어는 CSS 변수로 정의한다. 화면 내부 장식의 z-index는 해당 화면에 한정한다.
- 알림 CSS를 스타일 파일로 옮겼다. 토스트는 현재 dialog 안에 붙여 top layer 뒤에 가려지지 않게 한다. 확인창도 native dialog를 쓴다.
- 제목 메뉴는 ID-핸들러 매핑으로 등록하고, 동적 버튼은 data-action 이벤트 위임으로 연결한다.
- 이미지형 닫기/실행 컨트롤을 실제 button으로 바꿔 키보드 조작을 지원한다.
- 시간 정책·음악 수·인쇄 최대 개수는 `APP_CONFIG`, 레이어는 CSS 변수로 모았다.
- 기존 저장 키/데이터 필드와 사용자 기록 마이그레이션을 유지했다. 사용되지 않는 dayInfo 호환 getter와 오래된 관리자 진입/골드 조정 코드는 제거했다.
- 미참조 `title_bak.webp`를 제거하고, 공백이 있던 연습 팝업 파일명을 정상화했다.
- 문서는 `docs/`로 이동하고 현행 구현 기준으로 교체했다. 이전 문서는 Git 이력으로 조회 가능하다.
- LF 규칙, 전체 Prettier 포맷, lockfile, 자동 문법/에셋 검사와 GitHub Actions 검증을 추가했다.

## 암기 UI 평가 및 수정

기존 연습 화면은 단어·뜻·설명을 항상 함께 보여줘 읽기는 편하지만 스스로 답을 떠올릴 기회가 적었다.
이제 새 단어마다 뜻과 설명을 숨기고 `뜻 확인`으로 펼친다. 다음 단어로 이동하면 다시 숨긴다.
외움 표시는 확인 상태를 유지하며 같은 단어를 다시 발음하지 않는다. 버튼의 pressed/expanded 상태도 제공한다.
설명 전환은 클릭과 Enter/Space로 조작한다. 일반 연습 영역에서는 방향키와 Space도 사용할 수 있다.
배경 그림은 40%에서 30%로 줄이고 작은 높이에서는 추가 축소한다. 내용 영역은 스크롤 가능하다.

객관식은 빠른 의미 구분, 시간 제한 없는 주관식은 철자 회상, 발음은 음성 연결에 쓰기 좋다.
다만 `외웠어요`는 자기 평가이며 객관적인 장기 숙련도 판정이 아니다. 다음 학습 개선 우선순위는
오답 재학습, 복습 예정일/간격 반복, 단어별 정답 이력이다. 후속 수정에서는 결과 화면에서
이번 판 오답만 바로 연습하도록 연결했다. 중복을 제거하고 원본 설명·뜻 가리기를 유지한다.
미암기 필터에서 외움 표시 후 처음으로 돌아가지 않고 다음 단어를 보여준다.
간격 반복과 장기 정답 이력은 별도의 학습 정책/저장 모델이 필요한 후속 과제다.

## 후속 설계 리뷰와 추가 수정

- 전투 엔진의 DOM 조회·렌더링을 `ui/battle-view.js`로 옮겼다. `init.js`에서 렌더러를 주입한다.
  엔진은 문제·보기·스킬 상태를 소유하고 모델/콜백을 넘긴다. 렌더러는 게임/저장소를 직접 읽지 않는다.
- 출제 목록·철자 힌트/채점·보상·결과 집계는 `domain/battle-rules.js`로 분리했다.
  DOM 접근 시 오류가 나는 테스트 환경에서도 대체 렌더러로 실제 시작·채점·종료를 검증했다.
- 스킬이 버튼 텍스트와 `style.display`에 의존하던 구조를 제거했다. 주관식/마감/처리 중이면
  소모하지 않고, 힌트로 이미 제외한 보기를 모델에 기록한다. 채점 후 입력과 스킬 버튼을 비활성화한다.
- 타이머가 tick마다 0.1초를 빼면서 브라우저 지연에 따라 늘어나는 문제를 수정했다.
  실제 마감 시각에서 남은 시간을 계산하며, 갱신 전 늦게 들어온 클릭도 마감 후에는 오답이다.
  정답 보상도 실제 남은 시간을 사용한다. 백그라운드 탭에서는 시간이 계속 흐르는 규칙을 명시했다.
- 효과는 세션뿐 아니라 문제별 버전으로 구분한다. 이전 문제의 900ms 공격 정리와
  1초 골드 텍스트 제거 예약이 다음 문제의 효과를 지우는 문제를 수정했다. 오래된 보기 클릭도 무시한다.
- 연습/배틀 선택은 이미지와 투명한 절대 좌표 버튼 대신 label/select/fieldset/button 폼을 사용한다.
  실제 라디오를 표시하고 키보드 선택/포커스를 지원한다. 선택값 복원 코드를 공유하고
  JS 라디오 클래스 동기화, 이미지 좌표 계산, 기존 좌표 CSS와 두 팝업 이미지를 제거했다.
- 연습에 쓰이지 않는 숨겨진 문제 수 선택을 제거했다. 연습 시작이 배틀의 저장된 문제 수를
  10으로 덮어쓰는 결함도 함께 제거했다. Day 목록의 임의 60일 상한을 없애 실제 유효한 Day를 표시한다.
- Google 폰트 요청을 제거하고 시스템 폰트를 사용한다. 브라우저 발음과 로컬 영어 음성을 우선한다.
  원격 TTS 폴백 제거는 음성 미지원 환경의 기능을 줄이는 변경이라 철회하고 복구했다.
  브라우저 발음이 없거나 실패할 때 폴백하며, 취소·이전 단어 오류에서는 다시 재생하지 않는다.
  수동 발음 후 단어 전환에서도 이전 음성을 중지한다. 폴백까지 실패한 수동 요청에는 안내하고 자동 읽기는 알림을 반복하지 않는다.
- 음악은 `preload="none"`을 사용하고 기술적인 파일명 대신 `배경음악 N`으로 표시한다.
  유한한 보스 덱을 무한이라고 표시하던 문구도 `전체 단어 도전`으로 바로잡았다.
- 통계 초기화 확인창의 오래된 비동기 응답이 새 관리 요청을 취소하던 경합을 수정했다.
- 모든 런타임/스타일 파일의 HTML 등록과 전투 모듈의 직접 참조 경계를 자동 검사한다.
  텍스트 기반 검사이므로 TypeScript/정적 분석 전체를 대체한다고 보지는 않는다.

## 검증

- 자동 회귀 테스트 70개: 저장소 손상/거부, 이전 세션/문제 콜백, 재시작, 실제 구매/장착 규칙,
  대체 정답 제외, 부족한 보기, 인쇄 이스케이프, 모달 재열기, 히스토리 증가 억제, 뜻 가리기와 발음 중복 방지.
  후속 검증에는 DOM 없는 렌더러 주입, 실제 시간/마감 후 클릭, 상태 기반 스킬, 오답 복습,
  필터 진행 위치, 연습 설정 보존, 미지원 발음, 비동기 확인 경합, Day 상한 제거를 추가했다.
- 전체 단어장 2,424개 항목의 Day/단어/뜻 및 각 Day 최소 출제 개수 검사.
- 전체 런타임/도구/테스트 문법, HTML/CSS 로컬 경로, 인라인 동작 재유입 검사.
- 전체 Prettier와 Git 공백 검사. `npm run check`를 CI와 로컬의 공통 검증 명령으로 사용한다.
- Edge에서 데스크톱과 375×667 화면, 연습 카드와 모달/뒤로 가기, 전투 진입 및 주관식,
  상점·장비·설정·통계의 실제 UI를 확인했다. 확인한 탭의 경고·오류 로그는 비어 있었다.
- 후속 UI는 데스크톱/375×667 Edge에서 선택 폼, Escape 포커스 복귀와 보스 오답→결과→오답 복습을 확인했다.
- 발음 폴백 5개 테스트: 브라우저 음성 우선/오류 폴백, 중복 요청 방지, 취소·이전 단어 오류,
  단어 전환/나가기 중지, 원격 실패와 나간 뒤 늦은 Promise 거부를 검증했다.
- Google TTS에 실제 단어 요청을 보내 HTTP 200, `audio/mpeg` 응답을 확인했다.
  Android/iOS 실기기의 발음·음악 정책과 모든 환경의 실제 청취는 검증하지 않았다.

## 커밋 실명 점검

최초 검토한 도달 가능 이력은 17개이며 작성자 이름은 `obmaz`, 커미터는 `obmaz` 또는 `GitHub`이다.
후속 작업 전의 18개 이력에서도 작성자/커미터 이름은 동일한 별칭 범위였다.
메시지·트레일러에서도 실명으로 보이는 문자열은 발견하지 못했다.
다만 작성자와 일부 커미터에는 개인 Gmail 주소(`zamb…@gmail.com`)가 남아 있다.
별칭이 실제 이름인지, 프로필/삭제된 커밋에 다른 이름이 있는지는 Git 기록만으로 판단할 수 없다.
기존 이력을 재작성하지 않았으며 새 커밋도 현재 저장소의 작성자 설정을 사용한다.

## 설계 제약 후속 개선 (2026-10-06)

- 전투를 createBattleSession 팩토리로 변경했다. 데이터·정책·저장소·시계/타이머·화면·음악·알림을 app.js에서 주입한다.
  DOM뿐 아니라 window/navigator/performance 전역 조회도 세션에서 제거했다.
- 연습 카드 진행/외움/필터를 practice-session, DOM을 practice-view, 발음 요청 수명을 speech로 분리했다.
  브라우저 전역 없는 연습 테스트와 서로 다른 세션의 상태 격리를 추가했다.
  브라우저 음성 우선과 원격 Google TTS 폴백을 유지하고 단어 전환·빈 필터·나가기의 취소를 보존했다.
- 연습 세션·렌더러·발음에 타입 계약과 strict checkJs 검사를 추가했다. TypeScript는 개발 의존성이며
  런타임은 기존 JavaScript이다. CI/로컬의 npm run check에 타입 검사를 포함했다.
- 제목 메뉴는 텍스트 버튼과 Grid/Flex 배치로 변경했다. 각 학습 모드의 목적을 짧게 설명한다.
  이야기 화면도 본문/버튼의 일반 문서 흐름으로 바꿔 이미지 좌표·naturalWidth/Height 의존을 제거했다.
  작은 화면에서는 콘텐츠를 스크롤할 수 있고 viewport의 확대 금지를 해제했다.
- 미사용 보스 이야기 dialog, 숨겨진 중복 시작/상점/장비 버튼, overlay-layout과 오래된 제목/이야기 스타일,
  참조 없는 이미지 8개(총 247,414 bytes)를 제거했다.
- npm run build와 Pages artifact 배포 workflow를 추가했다. 런타임 파일 88개와 SHA-256 manifest만 배포하며
  도구/테스트/리뷰 문서는 웹 루트에서 제외한다. 같은 소스의 재빌드 결과와 stale 파일 제거를 검사한다.
  dist가 외부 경로를 가리키는 junction/symlink이면 삭제하기 전에 실패하도록 보호했다.
- 테스트 77개, 연습/발음 strict 타입 검사, 에셋/책임 경계 검사와 정적 빌드가 통과했다.
  Edge 데스크톱·375×667·320×480에서 제목 메뉴, 연습 뜻 가리기/단어 전환/나가기,
  설정 Escape 포커스 복귀, 주관식 정답과 골드 보상, 긴 이야기의 시작 버튼 노출을 확인했다.

  WebP로 최적화한 배포 에셋은 총 2,100,644 bytes이며 이미지 원본과 생성 프롬프트를 보존했다.
  파일별 용도와 전체 프롬프트는 [디자인 에셋](early-design-prompts.md)에 기록한다.

  도서관·훈련장·드래곤 탑으로 학습 모드를 구분하고 본문은 종이색 카드 위에 표시한다.

  설정 패널도 Flex로 표시하여 작은 화면에서 본문만 스크롤하고 닫기 버튼은 항상 보이도록 수정했다.
- 교체 후 참조 없는 이전 배경·제목·닫기/적용 이미지 9개를 삭제했다. 현재 캐릭터·몬스터는 보존했다.
- Edge 기본 데스크톱 및 375×667·320×480에서 메뉴, 스크롤 가능한 선택 폼/긴 이야기,
  연습 뜻 확인·단어 전환, 주관식 정답/보상, 전체 도전 오답/결과를 실제 조작해 확인했다.
  회귀 테스트 77개와 strict 타입·참조/경계 검사, 정적 빌드를 통과했다.

## 모바일 가독성과 랜덤 타이틀 보완 (2026-10-06)

- 고정 생성 로고를 HTML h1 타이틀로 교체했다. 킹왕짱·왕짱킹·킹짱왕·왕킹짱·짱킹왕·짱왕킹 중 무작위로 표시한다.
  초기 진입과 학습에서 제목으로 돌아올 때 화면/브라우저 제목을 함께 바꾸며 직전 제목은 반복하지 않는다.
  모달 메뉴를 여닫는 동안에는 제목이 유지된다. 여섯 순열·반복 제외·귀환/메뉴 전환 회귀 테스트를 추가했다.
- 메인은 큰 연습 버튼, 두 보조 모드, 하단 상점·장비·통계·설정 메뉴로 재배치했다.
  배경 채도와 불투명도를 줄이고 버튼에는 단색에 가까운 면·넓은 간격·큰 글자를 사용한다.
- 메뉴 아이콘 atlas는 내장 image_gen으로 간결한 모바일 게임 스타일로 다시 만들었다.
  필리그리·반짝임·작은 장식을 제거하고 34~48px에서도 실루엣을 구분하도록 했다.
  메뉴 창의 장식 프레임과 헤더 삽화를 제거하고 작은 아이콘과 본문, 고정 닫기 버튼을 사용한다.
- 참조 없는 기존 생성 로고·프레임·아이콘·상점 배경 4개를 제거했다. 현재 에셋 5개는 총 1,220,398 bytes로
  이전 2,100,644 bytes보다 약 42% 작다. 생성 원본과 최초·수정 프롬프트는 보존한다.
- 테스트 79개, strict 타입·참조/책임 경계·포맷 검사가 통과했다. 정적 빌드는 런타임 파일 85개다.
  Edge 375×667에서 메인 전체 버튼, 상점, 선택 폼, 연습과 타이틀 귀환을 확인했다.
  320×480에서는 간결한 설정 패널의 내부 스크롤·고정 닫기 버튼과 가로 넘침 없음도 확인했다.

## 생성 UI 시안 기반 길드 디자인 (2026-10-06)

- 전체 로비 UI를 내장 image_gen으로 먼저 생성하고, 이를 참조해 로비 배경·여섯 순열 로고 atlas·메뉴 아이콘·나무/양피지 패널·비취 버튼을 제작했다.
  [전체 시안과 에셋/정확한 프롬프트](design-history.md)를 보존했다. 기존 스타일의 글자 타이틀과 단색 메뉴를 교체했다.
- 메인, 학습 선택, 이야기, 상점, 장비/상세, 통계, 설정/하위 패널, 확인, 결과에 생성 스킨을 공유한다.
  프레임은 9-slice로 모서리를 유지하며 늘어난다. 메뉴 조작은 실제 HTML 컨트롤과 Grid/Flex, native dialog/top layer를 사용한다.
  읽어야 하는 단어·설명·가격·통계는 HTML이고 밝고 단순한 영역에 배치한다.
- 보이는 타이틀도 여섯 생성 로고다. 로고 선택과 접근성 h1, document.title이 함께 갱신되는 회귀 검증을 보강했다.
  학습 귀환에서는 직전 이름을 제외하고, 메뉴를 여닫을 때는 이름을 유지한다.
- 작은 화면에서 선택 창의 시작 버튼이 스크롤 아래로 밀리는 문제를 고쳤다. 본문만 스크롤하고 제목/시작/취소는 고정한다.
  학습 조작 버튼은 최소 44px 높이를 적용했다. 상점 설명의 인라인 색상을 CSS 클래스로 옮겨 밝은 테마의 대비를 확보하고 중복 상품 마크업을 통합했다.
- 미사용 academy/mobile-emblems를 제거했다. 배포용 생성 에셋 8개는 총 1,562,524 bytes다.
  전체 시안은 design/에 두고 배포에서는 제외한다. PNG 원본은 생성 도구 디렉터리에 보존한다.
- Edge 375×667에서 메인, 상점, 설정, 통계, 장비/상세, 연습 선택·뜻 확인·단어 이동·다른 생성 타이틀로 귀환을 실제 조작해 확인했다.
  320×480에서 메인의 7개 버튼이 화면 안에 들어오고 가로 넘침이 없으며 배틀 선택 창의 시작/취소가 항상 보임을 확인했다.
  브라우저 경고/오류 로그가 없었다. 회귀 테스트 79개, strict 타입·참조/책임 경계·포맷 검사와 런타임 파일 88개 정적 빌드를 통과했다.
- 공개 사이트의 큰 화면 검증에서 로고가 고정 헤더보다 커져 위아래가 잘리는 경우를 추가로 보정했다.
  로고는 3:1 셀 비율을 유지하고 헤더 높이의 세 배 이하로 너비를 제한하여 모바일/큰 화면 모두 전체를 표시한다.
- 공개 사이트에서 이전 CSS를 계속 쓰는 브라우저 캐시를 확인했다. 빌드가 이미지 → CSS → HTML 순서로 내용 해시 버전을 붙이도록 개선했다.
  이미지가 바뀌면 상위 CSS/HTML 버전도 바뀌며, 원본·외부 URL·classic script 순서를 보존하는 회귀 검증을 추가했다.
  최종 회귀 테스트는 80개다.

## 남은 설계 제약

- classic script의 명시적 로드 순서를 유지하여 원본과 dist 모두 file://로 실행할 수 있다.
  핵심 세션은 팩토리로 분리했지만 상점/통계/설정 등 주변 기능의 전역 API와 전체 TypeScript 타입 검사는 남아 있다.
  전면 ES modules 전환은 file:// 지원을 포기하거나 번들을 도입하는 배포 정책 변경과 함께 진행해야 한다.
- 관리자 숫자 암호는 로컬 데이터 수정의 실수 방지용이며 서버 인증 수단이 아니다. 서버 없이 인증을 보장할 수 없다.
- 발음 지원/품질/오프라인 여부는 브라우저와 설치 음성에 따라 다르다.
  원격 Google TTS는 보완용 비공식 폴백이며 네트워크와 서비스 가용성에 의존한다. 음성 기능을 제거하지 않았다.
- 보스는 전체 단어를 한 번씩 푸는 유한 도전이다. 간격 반복/단어별 장기 이력은 학습 정책·저장 스키마를 새로 정해야 한다.
  계정 동기화는 서버/인증이 필요하다. 이번 구조 정리에서 게임 규칙이나 저장 데이터 계약을 바꾸지 않았다.
