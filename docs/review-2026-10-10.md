# 2026-10-10 전체 코드 리뷰

기준 커밋은 `6a6414c`다. 현행 문서, 정적 검사, 도메인·세션·렌더러 경계, 저장·보상·장비·스토리·행맨, 비동기 수명과 반응형 화면을 다시 검토했다.

P1과 P2 결함은 확인하지 않았다. P3에서는 전투 세션과 총공세 세션이 난수 공급원을 직접 읽어 구성 루트의 주입 경계를 우회하는 문제를 확인했다. 전투 방향 선택, 총공세의 영문/한글 방향, 총공세 변형 선택이 테스트에서 재현되지 않아 작은 변경에도 불안정할 수 있었다.

## 수정 코드 재리뷰

난수 호출은 게임 세션 내부에서 제거됐고 구성 루트에만 남았다. 도메인 파일은 브라우저·저장소를 참조하지 않으며 렌더러는 `game`·`db`를 직접 읽지 않는다. 기존 저장 키와 화면 ID, 전투 보상·왕관·장비 규칙은 변경하지 않았다. 행맨의 힌트/정답 예약 영역 변경도 별도 회귀 테스트와 함께 확인했다.

`npm run check`, `npm run build`, 전체 테스트 234개, 행맨 테스트 3개, 실제 화면 390×844·320×427·768×1024·844×390 검증을 통과했다.

확인한 범위에서 미해결 P1~P3는 없다. 주변 서비스의 전역 연결과 일부 UI HTML 문자열 렌더링은 현재 classic-script 구조와 기존 캐시 계약을 유지하기 위한 현행 설계로 남겼다.
