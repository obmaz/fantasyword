# 사용자 요구사항과 결정

구현을 되돌리지 않도록 유지할 사용자 의도를 정리한다. 구체적인 게임 규칙·수치·저장 형식은
[현행 사양](spec.md), 가격은 [경제 기준](economy.md), 이미지 경로는 [디자인 에셋](design-assets.md)에서 관리한다.

## 디자인 의도

- 웹 관리 화면보다 게임다운 만화풍 UI를 사용한다. 차분한 초록 숲·크림색·남자아이 모험가를 유지하고 화려한 배경·강한 입체감·크고 하얀 시작 버튼을 피한다.
- [승인된 시작 메뉴](design/approved-lobby.webp)와 [내부 메뉴](design/approved-menus.webp)의 재질을 실제 생성형 이미지 부품으로 구현한다. 버튼·아이콘·패널을 분리하며 글자·가격·문제·상태는 읽을 수 있는 HTML로 표시한다.
- 전체 메뉴를 통이미지와 좌표 기반 클릭 영역으로 만들지 않는다. 아이템 아이콘을 배경으로 확대하지 않고 게임별 전용 생성 장면을 사용한다.
- 승인 시안에 그려진 예시 가격·슬롯·뒤로 버튼은 구현 계약이 아니다. 최종 메뉴 구성과 실제 데이터는 현행 사양을 따른다.

## 메뉴와 화면

- 로비는 스토리·붉은 도전·연습을 한 줄로 놓고 작은 아이콘을 글자 왼쪽에 둔다. 상점·장비·통계·설정은 아래 개별 이미지 버튼이다.
- 생존 도전은 도전 설정의 전투 유형으로 통합한다. 별도 로비 버튼과 미니게임 테스트 바로가기를 추가하지 않는다. 테스트 게임은 잠긴 설정의 어드민 영역에 둔다.
- 내부 메뉴와 결과는 우상단 X로 닫는다. 같은 기능의 하단 돌아가기·닫기를 중복 배치하지 않는다. 팝업 제목의 크기·굵기·줄 높이와 상하 여백을 맞춘다.
- 일반 실행은 밝고 차분한 파랑, 취소는 회색, 초기화·삭제는 붉은색 이미지 버튼으로 구분한다.
- 다시하기 버튼은 일반 녹색 이미지 버튼을 사용한다.
- 연속 공격은 캐릭터 옆에 배경·아이콘 없이 `Combo 숫자` 글자만 표시한다. 보너스는 3회마다 적용하고 숫자는 계속 누적한다.
- 밝은 입력칸·select/option은 어두운 글자, 어두운 패널은 밝은 글자다. 답안 번호는 숨기고 글자·콤보·골드·상단 조작의 정렬과 여백을 유지한다.
- 골드는 실제 자릿수에 맞춰 영역이 늘어난다. 표시를 위해 저장 값을 99,999로 제한하지 않는다. 음악 ON/OFF는 실제 재생 상태를 반영하고 OFF 사선을 표시한다.
- 연습은 풀이 → 단어 → 뜻을 바로 표시한다. 회상 안내·뜻 확인/숨기기 버튼을 다시 넣지 않는다. 본문 공간을 우선하고 긴 내용은 게임 프레임 안에서만 스크롤한다.
- 주관식은 게임 내 영어 키보드를 사용한다. 발음 중 음악은 잠시 멈추고 수동 발음은 아이콘과 ‘다시 듣기’로 안내한다.
- 설정의 문제 출력·통계 초기화는 각각 한 줄 전체 너비에 배치한다. 도전 라디오는 첫 진입부터 선택 상태가 분명해야 한다.

## 비율과 전체화면

게임 영역은 세로가 더 긴 최대 가로:세로 3:4이며 긴 폰에서는 세로 공간을 사용한다.
로비·연습·배틀에 같은 크기 계산을 적용하고 데스크톱·가로 회전에서도 가운데 세로 프레임을 유지한다.
전체화면은 모든 화면·팝업에서 게임 프레임 우상단의 같은 위치에 공통 버튼 하나로 표시한다.
버튼이 제목·닫기·음악 조작과 겹치거나 브라우저 오른쪽 끝으로 나가면 안 된다.

## 게임과 장비

- 스토리는 긴 갈림길 지도에서 연결된 다음 지점만 선택한다. 구간별 들판·강·호수·협곡·설산·화산을 좁은 화면에서도 구별하고 경로는 단순한 실선으로 표시한다.
- 지점 입장은 한 번 확인한 뒤 바로 게임을 시작한다. 비전투 지점이 연속되지 않게 하고 숨겨진 ? 결과·상자 지급·왕관·Day 배정과 진행은 저장한다.
- 스토리 안에서 현재 단어장의 지도를 골드로 초기화한다. 불가능하면 보유 금액·부족분이나 저장 실패 이유를 표시한다.
- 미니보스는 드래곤 외형으로 한국어 뜻 철자 조립을 출제한다. 사자성어·속담·단어 대장간은 영어 메인 단어장과 분리하고 전용 문제 화면을 사용한다.
- 속담·사자성어도 영어와 같은 위치에 캐릭터·몬스터를 표시하고 정답 시 공격한다.
- 야바위는 서로 다른 색·숫자의 주사위 세 개를 숨긴 컵을 추적한다. 2배 도전도 컵을 찾으며 색상·숫자를 따로 입력하는 방식으로 되돌리지 않는다.
- 행맨은 마지막 기회·정답 완료·패배 후 ‘뜻’을 보여주고 새 단어에서 감춘다.
- 장비 이름은 D&D 분위기의 무기·마법 장비 용어를 쓰고 가격은 실제 문제 풀이 수입으로 평가한다. 장비는 외형뿐 아니라 학습·전투 역할을 갖는다.
- 오른손/왼손과 양발은 각 쌍이 같은 행이다. 장갑은 전용 슬롯을 사용한다. 장착 가능 위치·상점 설명·실제 능력·저장 복원은 같은 규칙을 따른다.
- 장비/전투 아바타는 실제 장착 상태를 반영한다. 빈 손·빈 슬롯에 기본 검을 표시하지 않는다. 무기·칼집 없는 몸 그림에 장비별 고유 부품을 손잡이 위치에 맞춰 겹친다.
- 오른손 무기 형태와 왼손 속성·방패는 독립적으로 표현하고 reduced motion을 유지한다.

## 데이터와 작업 방식

능률보카 고등 기본 (2025개정)은 4번 단어장으로 전체 Day·파생어·구동사·원래 뜻을 보존한다.
영어/한국어 풀이의 사전 출처와 공유 유사 오답 후보를 유지한다.
기존 골드·아이템 ID·단어장 기록을 임의로 초기화하지 않는다.

수정은 검증·빌드 후 항상 푸시·배포하고 실서비스 반영까지 확인한다.
완료한 몬스터별 문제·복수 퀘스트·장비 역할·무기 모션을 다시 계획 단계로 되돌리지 않는다.
새 기능·전면 재설계·계정 동기화는 별도 요청이 필요하며 문서의 제약 목록을 승인된 로드맵으로 취급하지 않는다.
