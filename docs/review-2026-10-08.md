## 컨벤션·구조 보완

- 연습의 사용하지 않는 answerVisible·뜻 숨기기 API·Space 단축키를 제거하고 타입/기존 동작 테스트를 실제 화면 계약에 맞췄다.
- 상점과 장착 요약의 데이터 템플릿을 escapeHTML로 처리했다.
- 문제지 선택 전에 단어·뜻 중복을 제거한다. 기존 방식은 한 묶음을 고른 뒤에만 사용 표시를 해 동일 묶음의 중복을 놓쳤다.
- 로비 행동이 아직 실행되지 않은 시작 예약을 취소하도록 방어했다. 실제 native dialog는 전환 중 로비 클릭을 차단했으므로 이 항목을 P2에 포함하지 않았다.
- 낙하전 렌더러를 HTML에 등록하고 책임 경계 검사에 추가했다. game 폴더에서 DOM 메서드를 다른 별칭으로 호출해도 검사에 걸린다.
- 기존 script/CSS 순서, 저장 키·아이템 ID와 작성자 계약을 유지했다. 승인된 이미지 부품을 재사용했다.

## 변경 코드 재리뷰

시간 만료 직전/직후, 중복 답안, 오래된 선택지·프레임·TTS 오류, 종료 후 재시작,
실패한 발음, 음악 OFF/ON·곡 변경, 전체화면 거부·대기 중 취소·노드 제거를 다시 확인했다.
스토리 결과의 복습/복수/일반 모드 이동과 출력의 중복·보기가 부족한 경우도 기존 테스트와 대조했다.

재리뷰에서 새 렌더러의 native 타이머를 객체 메서드로 호출하면 브라우저에서 Illegal invocation이 난다는 것을
실제 정답 클릭으로 발견해, 주입된 함수를 분리해 호출하도록 수정했다. 발사체의 시작점도 기존 CSS의 플레이어 위치를 유지했다.
이 문제들은 푸시 전에 수정했고 수정 후 브라우저 오류는 없었다.

확인한 범위에서 **미해결 P1·P2는 없다.** 전체 앱 타입 검사, 주변 서비스의 전역 결합,
큰 CSS cascade 통합은 남은 구조 제약이며 현재 동작 오류로 분류하지 않는다.
브라우저 TTS 음질·설치 음성 및 원격 TTS 가용성은 환경에 의존한다.
