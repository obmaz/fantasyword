# 현행 게임 사양

2026-10-08 구현 기준. 개발 원본은 HTML/CSS/JavaScript 정적 앱이며 빌드 없이 실행된다.
`obmaz/fantasyword`는 push 시 GitHub Actions 검증/빌드를 실행하며 배포는 `Deploy Pages` 수동 실행이다.
현재 [dokdok.quest](https://dokdok.quest/)는 이 저장소의 `dist/` artifact를 GitHub Pages로 서비스하며 HTTPS를 강제한다.
개발은 Node.js 22 이상, CI는 24. 서버·계정·런타임 npm 의존성은 없다.

로비의 스토리 모드와 1일 전투 버튼은 승인된 로비 그림체에 맞춘 독립 생성 아이콘을 사용하며 이름은 HTML 텍스트다.
설정의 게임 완전 초기화는 별도 확인 뒤 모든 `v7_*` 저장 값과 `selectedGameDataSet`을 지우고 새로고침한다. 골드·장비·스토리 경로·외움·복수 퀘스트·통계·설정과 선택 단어장이 기본값으로 돌아간다. 같은 출처의 게임 외 저장 값은 지우지 않는다.

## 총공세

설정의 어드민 총공세 버튼에서 Day를 고른다. 해당 Day의 모든 단어를 섞어 중복 없이 한 번씩 출제하며 영어 또는 한국어 방향도 무작위로 선택한다. 단어를 누르면 아래에 해당 뜻 또는 영어 보기 최대 4개가 나온다. 제한 시간은 `5초 + 단어 수 × 3초`이며, 정답을 고르면 공격 효과와 6 G를 얻는다. 오답과 바닥에 닿은 단어는 생명을 1개 차감하고 제거한다. 생명 5개를 모두 잃으면 종료하며, 모든 단어를 맞히면 승리한다.
매 판 총공세 도박 효과 하나가 무작위로 적용된다. 기본, 적 등장 가속, 일부 적 하강 가속 중 하나이며 별도 구매가 없다. 총공세 전용 3초 정지 장치는 Day마다 1개씩 기본 지급되는 일회성 아이템이다.
등장 간격은 2.4초에서 최소 0.8초까지, 낙하 속도는 시간에 따라 증가한다. 나가기·결과 버튼은 마을로 돌아가고 진행 중인 단어와 타이머를 정리한다.
프레임 지연과 배경 탭 시간도 총공세 제한 시간에 포함하며 마감 후 제출한 답에는 보상을 주지 않는다. 종료 시 공격 효과와 예약된 정리 작업도 제거한다.
정지 장치는 한 판에 한 번만 사용하고 실제 경과 시간 중 최대 3초만 제외한다. 정지 종료 이후 지연 시간은 낙하와 제한 시간에 포함한다. 선택·정답·아이템 입력 전에 도착선 접촉도 판정해 늦은 입력으로 생명 차감을 피하지 못한다.
선택 전부터 하단에 보기 네 개가 들어갈 고정 높이 영역을 확보하며 선택·해제에 따라 필드 크기를 바꾸지 않는다. 배경은 상단부터 하단 보기 뒤까지 한 장으로 이어진다. 필드 높이의 84%에 도착선을 표시하며 단어의 아래쪽이 선에 닿으면 생명이 1개 차감된다.
총공세 나가기는 다른 게임과 동일한 44px 사각형 이미지에 `나가기` 문구를 표시한다.
연습과 총공세의 상단 조작 영역은 각 모드의 배경 그림이 이어지며, 철자 조합 타일의 글자는 타일 정중앙에 배치한다.
결과창은 기존 생성 이미지 프레임과 양피지 정답/획득 통계칸을 사용하고 우상단 사각형 X로 닫는다. 장비 메뉴와 전투·총공세 결과에는 중복 마을 버튼을 표시하지 않는다. 작은 화면에서는 엠블럼과 여백을 줄인다.

## 단어장과 연습

단어장 1번 1,198개/60일, 2번 896개/30일, 3번 330개/11일, 4번 1,595개/40일. 총 4,019개다.
4번은 `능률보카 고등 기본 (2025개정)`의 Day 1~40 전체를 제공한다. 파생어·구동사를 포함하며 Day 26은 원본대로 35개, 나머지는 각 40개다. 첨부 시험지의 순서와 뜻을 유지한다. 영어 풀이는 Oxford, 한국어 풀이는 국립국어원 표준국어대사전의 해당 의미를 참고해 학습용으로 짧게 정리하고 각 항목에 출처 URL을 기록했다. 자세한 기준은 [단어장 4 출처](vocabulary-book-4.md)를 따른다.
선택 단어장에 맞춰 단어·스토리·Day 목록을 로드한다. 통계와 외움 표시는 `book-ID`별이다.

학습 모드의 표시 이름은 로비·선택창·게임·접근성 안내 모두 `연습`으로 통일한다. 내부 practice ID와 저장 키는 유지한다.
모든 모드 선택창의 녹색 배경 위 항목 제목(출제/학습 범위·문제 수·문제 유형)은 밝은 크림색이다. 밝은 입력칸·선택지의 어두운 글자는 유지하며 단어 모험의 설명 전환 안내도 밝은 색으로 표시한다.
단어 모험은 Day/전체의 영어 카드와 뜻·설명을 바로 보여준다. 뜻 회상 문구와 확인/숨기기 버튼은 표시하지 않는다.
풀이 → 단어 → 뜻 순서로 표시하며 본문을 위해 배경 높이가 먼저 줄어든다. 짧은 화면은 카드·버튼 여백을 줄이고 높이 420px 이하에서는 풀이 아래 단어와 뜻을 나란히 배치한다. 내용이 실제로 넘칠 때만 본문 안에서 스크롤하며 하단 조작은 항상 표시한다.
이전/다음, 영문/한글 설명 전환, 수동/자동 발음, 외움 표시와 전체/외움/미암기 필터를 지원한다.
수동 발음 버튼은 음표 이미지와 `다시 듣기` 문구를 함께 표시한다.
필터 목록에서 현재 단어가 빠지면 같은 위치의 다음 단어로 진행한다.
결과의 틀린 단어 복습은 이번 판 오답을 중복 없이 모으고 원본 설명을 유지한다.
스토리 결과에서 복습이나 복수 목록으로 이동하면 해당 결과의 지도 복귀 상태를 정리한다.
외움 표시는 자기 평가이며 생존 도전의 장기 숙련도/간격 반복 예약은 없다.

## 도전·스토리와 몬스터

시작 메뉴의 모드는 `스토리·도전·연습` 한 줄이며 작은 아이콘을 각 버튼의 글자 왼쪽에 둔다. 도전은 범위를 고른 뒤 스토리 카드나 경로 선택 없이 바로 시작한다. 문제 유형 아래 전투 유형(일반 전투/전체 단어 도전)을 선택하며 `v7_last_battle_type`으로 복원한다. 전체 단어 도전은 범위·문제 수 선택을 비활성화하고 선택한 문제 유형으로 단어장 전체를 중복 없이 출제한다. 첫 오답·시간 초과에 종료하며 방패 재시도는 적용하지 않는다. 내부 boss 모드와 최고 연속 정답 기록은 유지한다.
스토리는 지도 위 15단계·31개 지점을 진행한다. 한 길·합류·2~3갈래 분기를 섞고 실선으로 연결한다. 이전 선택과 연결된 다음 지점만 고를 수 있다. 암시장·상자·도박장·?·속담·단어 대장간 뒤에는 전투가 이어져 비전투 지점이 연속되지 않으며 모든 지점에서 다음 길이 열린다. ?의 결과를 공개해도 연결은 바뀌지 않는다. 지점 선택 뒤 진행 확인창을 거치며, 고정 뜻/철자/듣기 전투의 Day는 확인한 뒤 지도에 표시한다. 이미 배정한 Day를 다른 지점에 중복 배정하지 않고 남는 Day가 없으면 전체 범위를 사용한다. 기존 진행·경로는 보존한다. 메뉴 안의 스토리 초기화는 확인 후 50골드를 차감하고 현재 단어장의 진행·경로·왕관·이벤트와 지점 배치를 다시 만든다. 골드와 관련 기록은 함께 저장하며 부족하거나 저장에 실패하면 보존한다. 배치는 `v7_story_layout_book-ID`에 저장한다.

전투는 선택 단어장 전체에서 섞어 8문제, 고정 뜻/철자/듣기는 6문제를 출제한다. 미니보스는 드래곤 외형으로 한국어 뜻을 보고 철자를 조립하는 5문제다. 정답에 없는 방해 글자 3개를 포함한다. 마지막 보스는 영어 예문/풀이 8문제를 유지한다. 모든 전투 지점은 실제 오답 0·1·2개에 금·은·동 왕관을 주며 어떤 왕관이든 다음 단계를 연다. 오답 3개 이상·실패·중도 종료는 같은 지점으로 돌아간다. 방패 재도전의 첫 오답도 횟수에 포함한다. 통과 기준은 입장 카드에 표시한다. 스토리 전투의 문제 수는 도전 설정의 10/20/전체 선택과 독립적으로 적용한다. 총공세 칸은 게임 방식만 재사용해 8개 단어, 29초, 생명 5개와 3초 정지 장치 1개로 진행하며 8개 단어를 모두 처리하고 오답이 2개 이하여야 왕관과 함께 다음 단계가 열린다. 일반 총공세의 전부 정답 조건은 유지한다. 총공세 결과 X·나가기·뒤로 가기는 스토리 지도로 복귀한다.

‘?’ 지점은 전투·암시장·상자·총공세·사자성어·속담·단어 대장간 중 하나로 열리며 `v7_story_events_book-ID`에 결과를 저장해 재입장·새로고침으로 바꾸지 못한다. 상자는 단계에 따라 50~90골드를 한 번 주며 열 때 지급 기록과 진행을 저장한다. 열지 않고 닫으면 보상과 진행은 없다. 암시장 통과도 다음 단계를 연다. 암시장 전용 유물은 그림자 나침반(180, 스토리 제한 시간 +3초), 그림자의 랜턴(120, 스토리 무료 힌트 +1회), 수호의 시질(260, 스토리 재도전 +1회), 순례자의 메달리온(220, 스토리 상자 +30골드)이다. 일반 상점에서는 구매할 수 없다. 각 상품 구매 성공률은 75%이고 실패하면 상품 가격만 잃는다. 확률과 손실은 구매 전에 표시한다.

### 사자성어와 도박장

메인의 행맨·총공세·사자성어·야바위 직접 실행 버튼은 없다. 설정의 음악 OFF→ON을 연속 3회 반복하면 골드 수정과 여섯 게임의 버튼이 함께 열린다. 같은 메뉴 이미지 재질과 한국어 이름을 사용하며 영어 버튼 부제는 없다. 잠긴 상태에서는 실행도 차단하고 설정을 닫으면 다시 잠근다. 스토리의 사자성어/도박장 진입은 어드민과 독립적이다. 야바위 시작 때 주사위 색과 숫자를 기억하라는 문구는 표시하지 않는다.

사자성어는 영어 단어장·Day·인쇄 풀과 독립된 `data/story-idioms.js` 120개다. 중고등학교 수준의 4단계, 단계당 30개이며 4단계가 가장 어렵다. 난이도는 게임 편집 기준이며 정의와 출처는 국립국어원 표준국어대사전으로 확인했다. 뜻을 보고 한국어 사자성어 4개 중 하나를 고른다. 스토리에서는 ?에서만 5문제씩 출제하며 깊이에 따라 난이도 1~4가 올라간다. 영어 통계·복수·오답 복습 풀에 섞지 않는다. 설정의 어드민 사자성어 버튼에서는 난이도를 고를 수 있으며 골드·장갑 횟수는 바꾸지 않는다.

도박장 지점은 야바위를 연다. 세 컵 모두에 주사위를 하나씩 넣는다. 빨강·파랑·노랑·초록 중 서로 다른 세 색상과 1~6 중 서로 다른 세 숫자를 사용해 질문의 정답 컵을 하나로 정한다. 처음에는 세 주사위를 모두 보여주고 섞기 시작 때 감춘다. 540ms 이동과 80ms 간격으로 7번 교환해 눈으로 쫓을 수 있게 한다. 섞는 중에는 선택할 수 없다. 섞은 뒤에만 특정 색상 또는 숫자의 주사위가 든 컵을 묻는다. 맞히면 10골드를 받거나 2배 도전을 선택한다. 2배 도전은 주사위를 다시 공개하지 않고 다른 주사위를 반대 속성(색상→숫자/숫자→색상)으로 물어 컵을 찾으면 20골드를 준다. 색상·숫자를 각각 고르는 이전 입력은 제거했다. 틀리면 0골드이며 기존 금화를 베팅하지 않는다. 결과 저장 뒤 지점을 완료하고 지도로 돌아간다. 저장 실패는 같은 결과만 재시도하며 중복 보상은 없다. 설정의 어드민 야바위는 실제 골드 대신 테스트 점수 0/10/20을 표시한다.

속담과 단어 대장간은 스토리 지도에서 직접 선택하거나 ? 결과로 등장하며 어드민 설정에서도 실행한다. 둘 다 비전투 퍼즐로 분류해 암시장·상자·도박장·? 및 다른 퍼즐과 연속으로 이어지지 않게 한다. 기존 저장된 지도 배치·진행은 보존하고 새 기본 지도/50골드 재배치에 새 지점을 포함한다.

- 속담: 별도 데이터 30개 중 중복 없이 5개를 골라 빈칸을 한국어 4개 보기로 완성한다. 답을 고른 뒤 전체 속담과 풀이를 공개한다. 오답 0·1·2개에 금·은·동 왕관, 오답 3개면 실패다. 완료 보상은 30골드다.
- 단어 대장간: 초급 3글자 영어 단어로 된 15개 출발/목표 쌍 중 3개를 고른다. 한 글자만 다른 실제 단어를 보기에서 선택해 목표 단어를 만든다. 별도 검토 단어 풀의 모든 이웃을 알파벳순으로 표시하며 목표로 갈 수 있는 경로를 보장한다. 각 문제의 변환 한도는 최단 거리 +2회다. 완료한 세 문제에서 최단 거리보다 더 쓴 변환의 합이 0·1·2이면 금·은·동 왕관이며 한도 소진 또는 추가 변환 3회 이상은 실패다. 완료 보상은 18골드다.

두 퍼즐은 결과의 왕관·골드·진행을 함께 저장하고 실패·중도 종료에는 보상이나 진행이 없다. 어드민은 실제 골드·영어 단어장 통계·장비 횟수를 바꾸지 않는다. 별도 데이터는 Day·인쇄 풀에 등록하지 않는다.

지도에는 마을·들판, 강·호수, 붉은 협곡, 설산, 화산으로 구간을 나눈 생성 배경을 적용한다. 반복되는 나무를 줄이고 좁은 화면의 중앙에서도 지형과 색 차이가 드러나게 하며, 실제 경로·지점을 HTML과 SVG로 표시한다. 현재 연결된 지점만 밝게 표시하고 갈 수 없는 모든 지점은 딤 처리하며 클릭·키보드 선택과 직접 실행을 막는다. 물음표를 누르면 정체를 감춘 확인 창이 열리며, 무료 입장 또는 100 G로 미리 확인을 선택할 수 있다. 확인 비용은 지점별 한 번만 차감하고 공개 결과는 단어장별로 저장한다. 골드가 부족하거나 닫으면 결과를 공개·생성하지 않는다. 듣기 문제는 듣기 버튼에 자동 여백을 넣지 않고 보기 위의 남는 공간만 늘려 보기를 하단에 유지한다.

철자 조립의 선택 타일은 알파벳순으로 표시한다. 한 줄에 맞지 않으면 두 줄의 글자 수 차이가 최대 하나가 되게 배치하고, 타일 안 글자는 가로·세로 중앙에 정렬한다. 화면 크기나 전체화면 전환 시 배치를 다시 계산한다.

스토리 지도·암시장·상자 팝업의 외곽은 다른 메뉴와 동일한 approved-frame 생성 이미지, 초록 재질, 크림색 제목, 사각형 닫기 버튼을 사용한다. 지도 안의 양피지는 유지한다. 제목은 고정하고 본문만 스크롤해 제목 뒤로 내용이 비치지 않는다.

암시장 구매는 각 상품의 이미지 버튼으로 표시하고 하단 나가기는 같은 재질을 사용한다. 나가기는 암시장 지점을 완료하고 지도로 복귀하며 우상단 X는 진행 없이 닫는다. 클리어한 지점은 이중 테두리로 표시하고, 새 전투 기록의 실제 오답이 0개면 금, 1개면 은, 2개면 동 왕관을 테두리 우상단에 작게 표시한다. 방패 재도전·시간 초과도 오답 횟수에 포함한다. 3개 이상 오답, 전투가 아닌 지점, 오답 기록이 없는 기존 클리어는 왕관 없이 테두리만 표시한다. 실패·중도 종료에는 클리어 표시를 남기지 않는다. 기록은 기존 단어장별 이벤트 저장에 추가한다.

범위는 Day/전체, 문제 수는 10/20/전체다. 새 기본 유형은 `monsters`이며 저장된 기존 유형은 복원한다.
객관식·주관식·혼합형도 유지한다. 혼합형은 가능한 범위에서 두 유형을 번갈아 출제한다.

| 몬스터 | 문제                                    | 시간·입력                         |
| ------ | --------------------------------------- | --------------------------------- |
| 슬라임 | 영어 단어 → 한국어 뜻 선택              | 객관식 제한 시간                  |
| 고블린 | 섞인 글자 조각으로 철자 조립            | 시간 제한 없음; 완성 전 공격 불가 |
| 박쥐   | 발음 듣기 → 한국어 뜻 선택              | 발음 완료 뒤 보기와 시간 활성화   |
| 드래곤 | 검토된 예문의 빈칸, 없으면 영어 뜻 풀이 | 시간 제한 없이 전체 단어 입력     |

일반 몬스터는 섞은 순서로 순환하고 마지막 문제는 드래곤이다.
고블린의 중복 글자는 별도 조각이며 정답에 필요한 글자 외에 흔한 모음·자음 조각 3개를 섞는다. 정답 글자 수를 채우면 제출할 수 있고 나머지 조각은 선택할 수 없다. 숙어의 공백/구두점은 유지하며 한 글자 지우기·전체 지우기·키보드 입력을 지원한다.
방해 글자는 정답에 없는 알파벳으로 고르고 흔한 글자가 부족하면 다른 알파벳으로 보충한다. 드래곤 설명에 정답 단어가 포함되면 그 부분을 빈칸으로 가린다.
드래곤 예문은 단어의 `exampleSentence` 또는 `data/battle-examples.js`를 사용하고 실제 목표 단어가 있을 때만 빈칸으로 만든다.

박쥐는 다시 들어도 시간이 늘지 않는다. 음성 실패/12초 미완료 시 같은 단어의 뜻 문제로 바뀌며 수동 전환도 가능하다. 듣기 문제는 질문 카드에 정답 단어를 표시하지 않는다.
문제 전환/나가기 이후 늦은 음성 콜백은 무시한다. 모든 단어는 브라우저 영어 TTS를 우선 사용하고, 음성 지원이 없거나 재생에 실패하면 원격 TTS를 사용한다. 발음 재생 중 배경음악은 일시정지하고 완료·취소 시 기존 재생 상태로 돌아간다.
몬스터 문제는 대소문자·앞뒤/연속 공백을 정규화한 전체 답으로 채점한다.
주관식은 첫 글자부터 전체 철자를 입력해야 정답이며 첫 글자가 빠진 입력은 오답이다. 앞뒤 공백과 대소문자는 무시한다.
주관식은 게임 내 QWERTY 영어 키보드 26글자와 백스페이스만 제공하며 밑줄 칸에 글자가 채워진다. readOnly와 inputmode=none으로 기기 키보드를 열지 않는다. 공백·구두점은 문제의 단어 형식에 맞춰 자동 입력하며 숫자·스페이스바·언어 전환 키는 없다. 물리 키보드의 영어·Backspace·Enter 제출은 유지하며 채점·종료 시 키를 잠근다. 캐릭터·문제판·키·공격 버튼은 승인한 숲 모험 시안의 이미지 부품을 사용한다.

선택 문제의 기본 시간은 10초, 모래시계 보유 시 15초다. 부츠의 안전한 길은 스토리 전투에서 추가 5초다.
실제 마감 시각을 검사하며 백그라운드 탭에서도 시간이 흐른다. 주관식/조립에는 시간 제한이 없지만 정답 골드는 풀이 시간이 길수록 줄어든다.
선택 문제는 객관식 통계, 조립/입력은 주관식 통계이며 결과에는 몬스터별 학습 방식과 전체 성적을 표시한다.
전체 단어 도전은 단어장 전체를 섞은 유한 덱으로 고른 문제 유형을 진행한다. 주관식은 드래곤 문제, 객관식·혼합형·몬스터별도 지원한다.

## 복수 퀘스트

오답은 뜻/단어와 몬스터를 단어장별로 저장한다. 새로고침 후에도 유지되며 원본 단어장에 없는 항목은 목록에서 제외된다.
로비와 결과에서 목록을 열 수 있다. 완료 전에는 뜻을 보여주고 영어 정답은 숨긴다.

1. 오답: `revenge` 상태로 즉시 재도전 가능.
2. 복수 모드에서 정답: 최초 +4 G, `recall`로 이동해 현재 시각부터 24시간 대기.
3. 대기 후 회상 정답: 최초 +8 G, `complete`로 이동.
4. 다시 틀리면 재도전으로 돌아가지만 이미 받은 보상은 반복 지급하지 않는다.

회상 가능 항목을 우선해 최대 10문제씩 진행한다. 일반 전투의 정답은 퀘스트 완료로 처리하지 않는다.
보너스는 단어·단어장별 한 번이며 무기/황금장갑/보물 경로 배율을 적용하지 않는다.
이는 오답에 대한 한 차례 24시간 회상이며 범용 장기 간격 반복 시스템은 아니다.

## 장비와 슬롯

머리·오른손·왼손·양발·장갑이 실제 슬롯이다. 정면 캐릭터 기준 오른손/오른발은 화면 왼쪽이다.
양손·양발은 각각 같은 행이며 기본 검은 오른손의 기본 장비다. 별도 무기 슬롯은 없다.

| 위치/조건 | 장비                                                                | 역할                                                             |
| --------- | ------------------------------------------------------------------- | ---------------------------------------------------------------- |
| 오른손    | 쇼트소드·롱소드·행운의 대거·풍요의 롱소드·황금의 배틀액스·속성 무기 | 주무기; 3연속 정답마다 +3 G 추가 공격; 경제 무기의 골드 배율     |
| 왼손      | 롱소드·행운의 대거·속성 무기·공허의 아케인 오브·철제 실드           | 보조 속성/외형; 실드는 전투당 오답 1회 무손실 재도전             |
| 머리      | 투구                                                                | 전투당 무료 힌트 1회: 오답 보기 제거 또는 정답 일부 철자/글자 수 |
| 양발      | 부츠 한 켤레                                                        | 스토리 전투의 안전한 길(시간 +5초) 또는 보물 길(기본 보상 +10%)  |
| 장갑      | 미다스의 건틀릿                                                     | 전용 슬롯 장착 중 정답 골드 ×1.5; 정답 10회 후 소모              |
| 보유 유물 | 모래시계·수호 방패 등                                               | 슬롯 없이 보유 조건으로 효과                                     |

같은 슬롯에 새 장비를 장착하면 기존 장비는 보관함으로 돌아가고 새 장비 하나만 표시한다. 장착 상태와 주무기 저장은 함께 변경하며 실패 시 이전 상태를 유지한다. 이미 장착된 슬롯의 장착 버튼은 비활성화한다.

풍요의 롱소드·황금의 배틀액스·쇼트소드는 오른손 전용, 공허의 아케인 오브·철제 실드는 왼손 전용이다.
장비 메뉴와 전투 캐릭터는 같은 착용 렌더러와 생성 이미지 부품을 사용한다. 몸 그림은 무기·칼집이 없는 전용 이미지이며 오른손 무기는 장착 레이어 하나에만 표시한다. 다른 무기를 장착하면 기본 검이 함께 남지 않고, 오른손을 비우면 기본 검만 돌아온다. 실제 장착한 손 장비·헬름·양발 부츠·건틀릿이 몸에 겹쳐 보이고, 해제·소모 후에는 즉시 사라진다.
헬름은 머리카락 위에 아이콘을 얹지 않고 같은 포즈의 헬름 착용 캐릭터로 전환한다. 무기 이름이 다르면 고유한 디자인을 사용하며, 칼·낫·창의 실제 손잡이를 양손의 회전 중심에 맞춘다. 주먹과 건틀릿이 손잡이 위에 보이며 무기와 얼굴이 겹치지 않게 한다.
장착 가능 손은 `weaponEquipSlots`가 UI·실제 장착·저장 복원에 공통 적용한다. 잘못된 손 요청은 거부한다.
부츠는 양발을 함께 장착한다. 장비는 소유만 하면 장착 능력이 활성화되지 않는다.
오답/방패 재시도는 콤보를 초기화한다. 방패로 막은 오답도 복습/퀘스트에 남고 첫 시도 골드·통계는 중복 처리하지 않는다.
시간 초과 방패 재시도는 최소 5초를 준다. 투구는 박쥐의 듣기가 완료되기 전 소모할 수 없다.
보기 제거 힌트는 오답 보기를 최소 하나 남기며, 한 글자 단어의 철자는 힌트에 표시하지 않는다.

수호의 부적은 오답 손실을 6 G에서 3 G로 줄이며 왼손 장착 실드와 별개다.
모래시계는 시간 +5초, 황금장갑은 장갑 슬롯 장착 중 정답 골드 ×1.5/10회, 가방은 보관함 용량 +1이다. 황금장갑은 보관함에 있을 때 효과·사용 차감이 없고 소모되면 슬롯에서도 제거된다. 이전 `v7_owned` 황금장갑은 `gloves` 슬롯에 자동 장착하며, 남은 횟수가 10회를 넘으면 10회로 낮추고 더 적은 횟수는 보존한다. 이후 해제한 상태도 새로고침 시 유지한다.

보관함은 기본 3칸이다. 장비 메뉴 상단과 상점에 사용량·최대 용량·빈칸을 표시한다. 배낭은 반복 구매 가능하며 한 번에 1칸을 늘린다. 상품 설명에 현재→구매 후 용량을 표시하고 구매 성공 시 늘어난 칸 수를 안내한다.
유료 힌트/필살기는 기존 구매 횟수를 사용한다. 구매는 실제 카탈로그 가격, 중복 제한·보관 용량을 검사한다.

## 보상과 전투 효과

기본 정답 보상은 선택 문제 최대 10 G, 주관식·조립·전체 단어 생존 도전 최대 12 G다. 총공세 정답은 고정 4 G이며 장비 배율·콤보는 적용하지 않는다.
선택 문제는 남은 시간 비율, 시간 제한이 없는 문제는 최대 30초의 풀이 시간에 따라 보상이 최대치에서 25%까지 줄어든다. 문제 수는 문제당 보상을 늘리지 않는다.
오른손 경제 무기 배율과 황금장갑을 적용한 뒤 보물 길·콤보·고정 퀘스트 보너스를 더한다.
3연속 정답의 +3 G는 줄어든 정답 보상에 더하며 화면에는 합계와 내역을 함께 표시한다. 보물 길의 +10%는 가장 가까운 정수로 반올림한다.
세부 반올림은 `battleRules.reward`와 전투 세션을 기준으로 한다. 오답 손실은 보유 골드를 넘지 않는다.
정답률 80%·문제당 4초·기본 장비의 10문제 전투 순수입은 약 50~75 G다. 이 기준에 따른 아이템 이름·가격·획득 속도와 소비 아이템 수익 상한은 [경제 기준](economy.md)을 따른다. 기존 골드·아이템 ID는 보존하고 건틀릿은 현행 10회 상한을 적용한다. 새 시작과 완전 초기화 후 기본 골드는 99이며 저장된 0골드는 그대로 유지한다.

단검은 이중 찌르기, 검은 베기/교차 베기, 도끼는 내려찍기와 지면 충격이다.
화염 상승 베기·서리 낫 휘두르기·뇌전 찌르기와 독립된 속성 이미지 효과를 사용한다.
왼손 속성이 오른손 무기 모션을 바꾸지 않고 보조 레이어로 겹친다. 콤보는 추가 공격을, 방패는 가드 그림을 표시한다.
효과 종료 720ms, 다음 문제 전환 800ms. 취소/종료/다음 문제에서 늦은 효과가 남지 않는다.
reduced motion에서는 이동/입자 대신 짧은 투명도 변화로 표시한다.

## UI·음성·설정

설정의 골드 수정·통계 초기화 관리 기능은 기본으로 숨긴다. 설정의 음악 재생을 OFF→ON으로 3번 연속 전환하면 현재 설정 창에서만 공개하며 기존 암호 확인은 유지한다. 전환 사이 5초가 지나거나 다른 설정을 바꾸거나 설정을 닫으면 연속 입력을 초기화한다. 문제 출력과 게임 완전 초기화는 일반 기능으로 유지한다.

가로:세로 최대 3:4의 세로 프레임이며 로비·연습·배틀 크기를 함께 계산한다. 짧은 세로 화면에서는 전투 장면과 답안 영역을 압축해 불필요한 내부 스크롤을 줄인다. 철자 조합·주관식 입력과 공격 버튼은 답안 영역 하단에 두고, 짧은 화면에서도 전체화면 버튼이 상단 상태 바 안에 들어오게 한다.
타이틀은 킹왕짱의 6가지 순열, 시작 배경은 숲/노을/달빛 중에서 직전 것을 제외해 선택한다.
시작과 학습에서 제목으로 돌아올 때 바뀌며 메뉴를 여닫을 때는 유지한다.

배틀은 상단의 큰 붉은 버튼이며 단어 모험/전체 단어 도전과 하단 내부 메뉴도 생성 이미지 바탕·독립 아이콘·HTML 문구로 구성한다. 로비 버튼은 기준 크기의 88%(이전보다 10% 확대)이며 내부 아이콘은 모드 버튼 너비의 22%, 하단 메뉴 너비의 28%로 줄여 여백을 확보한다.
팝업은 native dialog, 값·문제·입력·가격·통계는 HTML이다. 내부 메뉴는 중복 마을 버튼 없이 우상단 X로 닫고, 전체화면은 항상 게임 프레임 우상단이다. X와 나가기는 전체화면과 같은 사각형 이미지 재질을 쓰며 골드와 독립된 칸에 배치한다. 스토리 지도는 제목 아래 콘텐츠만 스크롤한다.

로비 우상단 복수 바로가기는 전용 생성 검·회전 화살표 아이콘과 ‘복수’ 글자를 세로로 배치하며 숫자 배지는 표시하지 않는다. 전체화면 버튼과 같은 44px 사각형 이미지 프레임 안에 아이콘 20px, 글자 10px을 배치해 겹침·넘침을 막는다. 복수 메뉴의 퀘스트 집계와 숫자는 유지한다.
로비 메뉴 버튼은 원래 크기의 80%로 중심 위치를 유지한다. 객관식 보기에는 번호를 표시하지 않고 채점 후 정답/오답 표시를 유지한다. 닫기가 필요한 팝업에는 우상단 X를 둔다.
단어장 변경과 통계 초기화에 쓰는 확인창은 짙은 패널 위에 밝은 안내 문구를 표시한다.
전투 골드는 범위 표시(전체/Day) 바로 옆 같은 줄이며, 배경 한 장이 상단 메뉴와 전투 영역 뒤로 이어진다.
로비·전투·메뉴의 골드 영역은 실제 숫자의 자릿수에 맞춰 늘어나며 고정 자릿수나 최소 너비를 예약하지 않는다. 좁은 화면에서 전투 상태 줄은 줄바꿈해 골드와 진행 표시가 겹치지 않게 한다.
주관식 문제판은 글자 높이·테두리·패딩을 포함한 최소 높이를 확보해 뜻의 아래쪽을 자르지 않는다. 긴 뜻은 줄바꿈하고, 화면에 다 담기 어려운 설명은 문제판 안에서 첫 줄부터 스크롤해 읽는다.
상단 조작·제목·캐릭터·문제·음악 선택·타이머의 기존 배치는 유지한다.
목록 아이콘과 ‘곡’ 표시의 곡 선택은 모든 높이에서 음악 ON/OFF 바로 앞에 둔다. ON/OFF의 음표 아이콘과 구분하며 선택된 곡 이름은 펼친 목록에서만 표시한다.
설정 내부 암호/인쇄/골드 편집은 패널 전환이다. 문제 출력은 독립 HTML 문제지/정답지이며 보기가 부족하면 주관식으로 대체한다.
출력 문제의 단어·뜻 중복을 먼저 제거하며 긴 보기와 답은 줄바꿈해 전부 표시한다. 내용이 A4 한 장을 넘으면 다음 페이지로 이어진다.
인쇄 출제는 기본 20문항, 최대 10·20·30문항 선택이다. 한/영 방향을 교대로 배치하고 혼합형은 절반을 객관식으로 만든다. 객관식은 같은 Day의 오답을 우선하며 부족하면 현재 단어장 전체에서 보충한다. 동일 영단어의 다른 뜻과 구분자로 나눈 뜻이 겹치는 단어는 오답에서 제외하고 정답 위치별 빈도 차이는 1 이하로 맞춘다. 의미가 다르게 쓰인 동의어까지 자동 판별하지는 못한다.
문제지는 흑백 A4 세로·14mm 여백·11pt 본문이며 이름/날짜/점수란과 주관식 답란을 제공한다. 두 문제씩 묶어 페이지를 넘기고 긴 내용은 추가 장으로 이어진다. 정답지는 번호·문제·정답 표로 별도 구성하며 인쇄 범위는 기본 문제지만, 정답지만, 둘 다를 선택할 수 있다. 독립 HTML은 다운로드와 새 창 열기를 함께 제공하며 브라우저의 인쇄/PDF 저장을 이용한다.
설정의 어드민 행맨은 뜻을 시작부터 공개하지 않고 알파벳을 고르는 7회 기회 게임이다. 오답마다 단두대와 졸라맨이 순서대로 그려지며, 마지막 기회와 정답 완료 후에 `뜻: ...`로 한국어 뜻을 공개하며, 패배 후에도 뜻을 유지한다. 새 단어를 시작하면 뜻을 다시 감춘다. 정답 단어를 완성하거나 기회를 모두 쓰면 다음 단어를 선택할 수 있으며, 나가기 버튼으로 로비에 돌아간다. 향후 스토리 지점에 연결할 수 있도록 게임 상태를 별도 모듈로 두었다.

행맨·도전·연습의 상단은 공통 생성기로 만든다. 나가기는 좌상단, 곡 선택·음악 ON/OFF는 우상단의 공통 전체화면 버튼 옆이다. 행맨 배경은 생성한 숲 공터이며, 알파벳은 주관식과 같은 이미지 QWERTY 키보드를 재사용하되 삭제 키는 제공하지 않는다. 선택한 글자는 잠그고, 새 단어·나가기 이후의 이전 키 입력은 무시한다.
로컬 관리 암호는 실수 방지용이며 서버 인증이 아니다.
설정의 토글 행은 아이콘·글자·스위치를 가운데 정렬하고 같은 좌우 패딩을 사용한다. 골드 증감은 실제 버튼의 −/+ 글자를 표시하며 44px 배치 칸과 버튼 크기를 맞춘다. 긴 골드 숫자는 글자 크기를 조정하고 필요한 경우 줄바꿈해 표시하며 값을 제한하지 않는다. 설정 본문 항목은 높이를 압축하지 않고 내부에서 스크롤한다.

배경음악 20곡은 로컬 MP3이며 첫 곡은 랜덤, 종료 후 순환한다. 실제 오디오 재생 상태를 ON/OFF와 사선 아이콘으로 표시한다.
곡 선택 select/option은 밝은 바탕·어두운 글자다. 음악은 `preload="none"`으로 필요할 때 로드한다.
발음은 Web Speech 영어 음성을 우선하고 실패 시 원격 Google TTS로 폴백한다.
첫 자동 발음부터 음악을 일시정지하고, 발음 중 음악 ON/곡 선택은 발음이 끝난 뒤에 재생한다.
취소·전환·나가기·자동 읽기 해제에서 음성을 중지한다. 원격 실패는 수동 발음에 안내하고 자동 발음은 알림을 반복하지 않는다.
원격 폴백과 일부 음성은 네트워크에 의존한다. 외부 폰트는 사용하지 않는다.

## 저장 계약

상점·암시장 구매는 골드와 상품/횟수/용량을 함께 저장한 후 화면과 메모리 상태에 반영한다. 저장 실패 시 비용·상품을 기존 상태로 복원한다. 물음표 공개/상자 보상도 골드와 이벤트 기록을 함께 저장한다. 클리어·새 모험 시작은 경로·단계·이벤트를 묶어 저장하며 진행 저장에 실패한 상자를 다시 들어가도 이미 받은 보상을 반복하지 않는다. 완전 초기화의 삭제 실패도 먼저 지운 키를 복원한다. localStorage는 여러 키의 브라우저 강제 종료까지 보장하는 트랜잭션 저장소는 아니다.

모든 진행은 브라우저 localStorage에 저장한다. 계정/서버 동기화는 없다.
`gameStorage`가 접근하고 `database.js`가 검증·레거시 장비/단어장 키 복원·영속화를 담당한다.

- `v7_gold`, `v7_owned`, `v7_equip`, `v7_dura`: 골드·보유·주무기·내구도.
- `v7_inventory`, `v7_equipped`, `v7_inventory_capacity`, `v7_skills`: 장비·장착·보관 용량·스킬.
- `v7_stats`, `v7_practice_memorized`, `v7_revenge_quests`: 단어장별 `book-ID` 기록.
- `v7_settings`, `v7_last_day`, `v7_last_count`, `v7_last_question_type`: 설정·선택 복원.

키/아이템 ID/단어장 ID 변경은 마이그레이션과 테스트를 함께 해야 한다.
통계 초기화는 통계 기능이며 브라우저 저장소 전체 삭제로 바꾸지 않는다. 저장 불가 시 알림을 표시하고 게임은 계속한다.

오른손 무기 교체 후 아바타·슬롯·연속 공격 아이콘은 새 무기를 표시하고 이전 무기는 보관함으로 돌아간다. 캐릭터 몸 그림의 HTML 버전 주소는 외형 갱신에서도 유지한다.
