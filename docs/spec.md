# 현행 게임 사양

HTML/CSS/JavaScript 정적 앱이다. 원본과 빌드 결과는 직접 열 수 있으며 서버·계정·런타임 npm 의존성이 없다.
조작은 이미지 다운로드 완료와 독립적으로 DOM 준비 직후 한 번만 초기화한다. 게임 진입은 닫기 애니메이션을 기다리지 않으며, 일반 팝업 닫기는 160ms이고 동작 줄이기에서는 즉시 닫힌다.
게임 규칙은 이 문서, 보상·가격 상세는 [경제 기준](economy.md), 구현 위치는 [아키텍처](architecture.md)에서 관리한다.
실행·검증·배포는 [작업 인계](handoff.md)를 따른다.

4번은 능률보카 고등 기본 (2025개정)이다. Day 26은 35개, 나머지는 각 40개이며 원본의 순서·뜻·파생어·구동사를 보존한다.
[범위와 사전 출처](vocabulary-book-4.md)를 따른다. 단어장 선택에 맞춰 데이터·Day·스토리를 로드하고 통계·외움·복수 기록은 `book-ID`로 분리한다.

연습은 Day/전체 범위에서 풀이 → 단어 → 뜻을 바로 표시한다. 회상 안내·뜻 확인/숨기기 버튼은 없다.
이전/다음, 영어/한국어 풀이 전환, 수동/자동 발음, 외움 표시와 전체/외움/미암기 필터를 지원한다.
필터에서 현재 단어가 빠지면 같은 위치의 다음 단어로 이동한다. 전투 오답 복습은 중복을 제거하고 원본 풀이를 유지한다.
짧은 화면에서는 배경·여백을 줄여 본문을 먼저 확보하고 필요한 경우 본문만 스크롤한다. 하단 조작은 화면 안에 유지한다.

## 도전과 전투

로비 모드는 스토리·도전·연습이다. 도전 설정의 문제 유형 아래에서 전투 유형을 고른다.

- 일반 전투: Day/전체 범위, 10/20/전체 문제 수와 몬스터별/객관식/주관식/혼합형을 선택한다. 선택 후 바로 시작한다.
- 생존 도전(전체 단어 도전): 선택 단어장 전체를 섞은 유한 덱으로 한 번씩 출제한다. 범위·문제 수는 비활성화하고 고른 문제 유형을 적용한다. 첫 오답·시간 초과에 종료하며 방패 재시도는 없다. 내부 `boss` 모드와 최고 연속 정답 기록은 유지한다.

새 기본 문제 유형은 `monsters`이며 기존 저장값을 복원한다. 혼합형은 가능한 범위에서 객관식·주관식을 번갈아 출제한다.
전투 Day·사자성어 난이도는 제목 옆에 표시한다. 이전 별도 Day 배지 없이 문제 시작·채점·다음 문제 전환이 동작한다.

| 몬스터 | 문제                              | 시간·입력                       |
| ------ | --------------------------------- | ------------------------------- |
| 슬라임 | 영어 단어 → 한국어 뜻 선택        | 객관식 제한 시간                |
| 고블린 | 한국어 뜻 → 철자 조립             | 시간 제한 없음; 완성 후 공격    |
| 박쥐   | 발음 듣기 → 한국어 뜻 선택        | 발음 완료 후 보기·타이머 활성화 |
| 드래곤 | 검토된 예문 빈칸 또는 영어 뜻풀이 | 시간 제한 없이 전체 철자 입력   |

일반 몬스터는 섞은 순서로 순환하며 마지막 문제는 드래곤이다.
드래곤 예문은 단어의 `exampleSentence` 또는 별도 예문 풀에서 실제 목표 단어가 있는 경우만 사용한다.
설명에 정답 단어가 있으면 빈칸으로 가린다.

철자 조립은 중복 글자도 개별 조각이며 답에 없는 흔한 알파벳 3개를 추가한다.
타일은 알파벳순·중앙 정렬이며 현재 키 크기와 화면 너비에 맞춰 줄을 나눈다.
두 줄일 때는 위아래 개수가 같거나 아래가 1개 더 많다(예: 11개는 5·6, 12개는 6·6).
더 긴 표현도 아래쪽 줄에 남는 타일을 배분하며 화면 회전·크기 변경 시 다시 계산한다. 키 크기는 공통 영어 키보드와 같다.
정답 글자 수를 채우면 제출할 수 있고 남은 조각은 잠근다. 한 글자/전체 지우기와 물리 키보드를 지원한다.
숙어의 공백·구두점은 보존한다.
철자 조립·주관식은 첫 글자를 답란의 힌트로 표시한다. 영어 뜻만 나오는 문제에서
알파벳이 6개를 넘으면 마지막 글자도 표시한다. 영어 예문 빈칸과 한국어 뜻 문제는 첫 글자만 표시한다.
표시된 첫·끝 글자는 고정되어 지울 수 없고 입력·조립은 나머지 빈칸부터 시작한다.
고정 글자의 타일은 제공하지 않으며 입력·지우기·전체 지우기·방패 재시도에도 고정 글자는 유지한다.
현재 입력할 빈칸은 커서로 표시하며 완성된 전체 단어로 채점한다.
오답 뒤 공개하는 정답은 밝은 파랑 배경 또는 글자로 강조한다.

주관식은 게임 내 QWERTY A–Z/삭제 키와 밑줄 칸을 사용한다. 기기 키보드는 열지 않는다.
공백·구두점은 정답 형식에 맞춰 자동 입력하고 물리 영어 키보드·Backspace·Enter도 지원한다.
고정 글자를 제외한 빈칸을 채우며 고정 글자와 입력 글자를 합친 전체 철자로 채점한다. 대소문자·앞뒤 공백은 무시하고 몬스터 문제는 연속 공백도 정규화한다.
채점/종료 후 키를 잠근다.

선택 문제의 기본 시간은 10초, 모래시계 보유 시 15초다. 부츠의 안전한 길은 스토리에서 5초를 더한다.
실제 마감 시각을 검사하며 백그라운드 탭에서도 시간이 흐른다. 조립/입력은 시간 제한이 없어도 풀이 시간에 따라 보상이 줄어든다.
박쥐는 다시 들어도 시간이 늘지 않으며 음성 실패/12초 미완료 또는 수동 전환 시 같은 단어의 뜻 문제로 바뀐다.
질문에 정답 단어를 표시하지 않고 문제 전환/나가기 후 늦은 발음 콜백을 무시한다.

선택 문제는 객관식 통계, 조립/입력은 주관식 통계다. 결과는 몬스터별 방식과 전체 성적, 오답 복습·복수 퀘스트를 제공한다.
스토리 결과에서 복습/복수로 이동하면 이전 결과의 지도 복귀 상태를 정리한다.

## 스토리 지도

15단계의 지점을 실선으로 연결한다. 단계별 지점 수와 분기·합류 위치가 다른 세 구조를 사용하며 배경은 공통이다.
기존형 → 합류·확장형 → 다중 분기형 → 기존형 순서로 순환한다. 구조마다 한 길·합류·1~3갈래를 섞고 이전 선택과 연결된 다음 지점만 허용한다.
갈 수 없는 지점은 어둡게 표시하며 클릭·키보드·직접 실행을 막는다.
암시장·상자·도박장·?·속담·대장간 등 비전투 지점은 서로 연결하지 않는다. ? 공개 후에도 원래 연결을 유지하고 모든 지점의 다음 길을 보장한다.
지도 제목은 고정하고 본문만 스크롤한다.

지점은 입장을 한 번 확인한 뒤 추가 전투 설명/시작 팝업 없이 바로 실행한다.
고정 뜻/철자/듣기의 Day는 확인 후 배정·표시하고 다른 지점에 중복 배정하지 않는다. 남는 Day가 없으면 전체 범위다.
기존 저장된 배치·진행을 보존하고 새 기본 지도와 초기화 배치에 속담·대장간을 포함한다.

| 전투 지점            | 출제                                   |
| -------------------- | -------------------------------------- |
| 일반 전투            | 단어장 전체에서 몬스터별 8문제         |
| 고정 뜻/철자/듣기    | 배정 Day에서 6문제                     |
| 8·12번째 행 미니보스 | 드래곤 외형, 한국어 뜻 철자 조립 5문제 |
| 마지막 보스          | 영어 예문/풀이 8문제                   |
| 총공세               | 8단어·29초·생명 5개·3초 정지 장치 1개  |

실제 오답 0/1/2개는 금/은/동 왕관이며 어떤 왕관이든 다음 단계를 연다.
방패 첫 오답과 시간 초과도 오답에 포함한다. 3개 이상 오답·실패·중도 종료는 진행 없이 같은 지점으로 돌아간다.
스토리 총공세는 모든 단어를 처리하고 오답 2개 이하여야 통과한다.
클리어 지점에는 이중 테두리와 왕관을 표시하며 오답 기록 없는 기존 클리어·비전투 지점은 테두리만 표시한다.
전투 문제 수는 도전 설정과 독립적이다. 결과 X·나가기·뒤로 가기는 스토리 지도로 돌아간다.

### 이벤트와 초기화

?는 전투·암시장·상자·총공세·사자성어·속담·대장간 중 하나다.
정체를 숨긴 확인창에서 무료 입장 또는 100 G 미리 확인을 고른다.
공개 결과와 비용은 지점별 한 번 저장하며 새로고침·재입장으로 결과를 바꾸지 못한다.
골드 부족/취소는 결과를 공개·생성하지 않는다.

상자는 단계별 50~90 G를 한 번 지급한다. 열 때 보상·지급 기록·진행을 저장하며 열지 않고 닫으면 진행하지 않는다.
암시장 상품은 일반 상점에서 살 수 없다. 상품별 성공률 75%, 실패 시 가격만 차감되며 위험을 구매 전에 안내한다.
상품 설명에는 실제 능력을 표시하며 ‘암시장에서만 획득’·‘암시장 전용’ 문구는 반복하지 않는다.
각 상품의 가격·역할은 [경제 기준](economy.md#가격과-성장)을 따른다.
암시장 하단 나가기는 지점을 완료하지만 우상단 X는 진행 없이 닫는다.

지도 안의 초기화는 50 G로 현재 단어장의 다음 갈림길 구조를 만들고 배치·진행·경로·왕관·이벤트를 다시 만든다.
최종 보스 클리어도 같은 순서로 다음 구조를 생성한다. 구조 순서는 단어장별로 유지하고 이벤트만 무작위 배치한다.
저장된 배치의 단계별 지점 수로 구조를 식별하므로 새 저장 키 없이 기존 지도·진행을 보존한다.
보유 골드와 부족분을 안내하고 부족하면 실행을 비활성화한다. 확인 순간에도 잔액을 재검사한다.
골드와 관련 기록을 함께 저장하며 저장 실패는 기록을 보존하고 같은 창에서 재시도한다.

### 학습 퍼즐과 야바위

사자성어·속담·대장간은 별도 데이터이며 영어 Day·인쇄·통계·복수·오답 복습에 섞지 않는다.
어드민 사자성어·야바위·속담·대장간은 실제 골드·장비 횟수를 바꾸지 않는다.

| 게임        | 출제·진행                                                                                                 | 완료 기준                                                             |
| ----------- | --------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------- |
| 사자성어    | 120개, 난이도 1~4 각 30개. 뜻을 보고 네 보기 중 선택. 스토리에서는 ? 전용 5문제, 깊이에 따라 난이도 증가  | 전투 왕관 기준 사용                                                   |
| 속담        | 70개, 난이도 1~4. 각 난이도 한 문항 + 추가 한 문항의 5문제. 답 뒤 전체 속담·풀이 공개                     | 오답 0/1/2개 왕관·30 G; 3개면 실패                                    |
| 단어 대장간 | 3글자 영어 출발/목표 15쌍 중 3문제. 한 글자만 다른 실제 단어로 변환. 현재·목표·보기·경로에 한국어 뜻 표시 | 최단 거리 초과 합계 0/1/2회 왕관·18 G; 한도 소진/초과 합계 3회면 실패 |

사자성어의 정의·출처는 국립국어원 표준국어대사전이며 난이도는 게임 편집 기준이다.
속담은 채점 후에도 문제·보기 위치를 유지하고 문제 빈칸에 파란 정답을 채운다.
객관식과 속담의 정답 보기는 실행 버튼과 같은 파란 이미지 배경·밝은 글자, 고른 오답 보기는 빨간 이미지 배경으로 표시한다.
해설에는 설명만 표시하고 정답을 반복하지 않는다.
속담 채점 후에도 모든 보기의 불투명도를 유지한다. 빈칸은 밝은 바탕·얇은 테두리의 단순한 사각형이며 공개한 답은 파랑으로 표시한다.
영어·사자성어·속담·대장간 보기는 같은 둥근 이미지·두 열·76px 최소 높이·폰트·8px 간격을 공유한다.
500px 이하의 짧은 화면에서는 모두 48px·16px 글자·5px 간격을 사용한다. 총공세의 작은 보기는 제외한다.
사자성어·속담 문제판은 내용에 맞게 작게 표시해 하단 보기와의 사이에 배경이 보이게 한다.
사자성어·속담은 영어 객관식과 같은 상단 장면 높이·문제 시작 위치를 사용한다. 채점한 보기에는 이미지 외의 테두리를 덧대지 않는다.
상단 장면에는 장착 장비를 반영한 모험가와 몬스터를 표시한다. 정답은 영어 전투와 같은 무기·속성 공격을,
오답은 몬스터 공격·피격을 표시한다. 속담은 별도 장면에서 공통 전투 뷰의 연출을 재사용하며 보상·아이템 횟수 규칙은 유지한다.
속담·단어 대장간은 상단 메타 띠에 모드 이름·문제 순서·실수 횟수를 표시한다.
속담 보기는 화면 하단에 유지하며 질문·해설 중에는 빈 다음 버튼 영역을 두지 않는다. 해설 후 자동 진행한다.
대장간의 다음 버튼은 하단에 유지하며 긴 본문만 스크롤한다.
속담·대장간은 직접 지점과 ?에 등장한다. 대장간은 검토된 70단어 풀의 모든 이웃을 알파벳순으로 표시하며
목표 경로를 보장하고 문제별 변환 한도는 최단 거리 +2회다.
두 퍼즐의 왕관·골드·진행은 함께 저장하고 실패·중도 종료에는 지급하지 않는다.

야바위 진행 버튼은 항상 하단에 놓고 사자성어 한 줄 보기와 동일한 최소 높이·폰트를 사용한다.
도박장 야바위는 세 컵에 서로 다른 색·숫자의 주사위 하나씩을 숨긴다.
색은 빨강/파랑/노랑/초록 중 세 개, 숫자는 1~6 중 세 개다.
처음 주사위를 모두 보여주고 540ms 이동·80ms 간격으로 7번 섞으며 섞는 중 선택은 막는다.
완료 후 특정 색상 또는 숫자의 주사위가 든 컵을 묻는다.
맞히면 50 G를 받거나 주사위를 재공개하지 않는 3배 도전을 고른다.
3배는 다른 주사위를 반대 속성으로 물어 컵을 맞히면 150 G다. 오답은 0 G이며 보유 골드를 베팅하지 않는다.
결과 저장 후 지도 지점을 완료한다. 저장 실패는 같은 결과만 재시도하고 중복 지급하지 않는다.
어드민은 테스트 점수 0/10/20을 표시한다.

## 총공세와 행맨

일반 총공세는 어드민 설정에서 Day를 골라 모든 단어를 섞어 한 번씩 출제한다.
영어/한국어 방향은 무작위이며 단어를 누르면 하단에 보기 최대 네 개가 나온다.
오답 후보는 현재 단어장 전체에서 구하며 한 방향이 부족하면 반대 방향을 사용한다.
두 방향 모두 보기를 만들 수 없으면 안내 후 나가며, 출제하지 않은 단어를 남겨 종료를 기다리게 하지 않는다.
정답 보상은 고정 4 G다. 오답/도착선 접촉은 단어를 제거하고 생명 1개를 차감한다.
생명은 5개, 제한 시간은 `5초 + 단어 수 × 3초`이며 모두 맞히면 승리한다.
등장 간격은 2.4초에서 최소 0.8초로, 낙하 속도는 경과 시간에 따라 증가한다.

엘리트 정답은 추가 8 G와 무작위 보상을 준다. 포션은 사용 횟수, 배낭은 용량 +1로 저장하며
유물은 용량을 확인한 뒤 보유 목록에 한 번만 저장한다. 보상 저장 실패·중복 유물·용량 부족이면 아이템은 지급하지 않는다.
이전 보상의 중복 보관과 미적용 포션·배낭은 로드 시 효과를 한 번만 복구한다.

매 판 기본/등장 가속/일부 하강 가속 중 도박 효과 하나와 3초 정지 장치 하나를 기본 지급한다.
정지는 한 번만 사용하고 실제 경과 시간 중 최대 3초만 제외한다.
배경 탭/프레임 지연과 입력 직전의 시간·도착선 접촉을 검사해 늦은 답에 보상을 주지 않는다.
보상 알림은 상단의 고정된 알림 칸에 표시하며 하단 스낵바로 보기를 가리지 않는다.
총공세 배경은 화면 전체의 단일 이미지로 표시하고 알림 칸·낙하 필드·하단 보기의 별도 배경으로 가리지 않는다. 글자는 그림자로 대비를 유지한다.
총공세는 공통 위치의 나가기·전체화면 아래에 시간·정답 수·하트·골드를 별도 상태 줄로 표시한다.
선택 전에도 하단 보기 영역 높이를 유지하고 단어 아래쪽이 필드 바닥(100%)의 주황색 실선에 닿으면 손실 처리한다. 별도 점선은 표시하지 않는다.
종료/나가기는 단어·프레임·효과·예약 작업을 정리한다. 스토리 진입 시에는 앞의 스토리 기준을 적용한다.

행맨은 설정의 어드민에서 실행한다. 7회 기회 안에 알파벳을 골라 완성하며 틀릴 때마다 그림을 추가한다.
마지막 기회·정답 완료·패배 후 한국어 뜻을 표시하고 새 단어에서 감춘다.
뜻은 단어 바로 아래의 고정 영역에 표시하며 숨겼을 때도 같은 공간을 유지한다.
키보드는 완료 후에도 같은 자리에 잠긴 상태로 남고, 다음 단어 버튼의 54px 영역도 처음부터 예약한다.
패배하면 단어 영역에 정답 철자를 채운다. 긴 뜻은 뜻 영역 안에서 스크롤한다.
행맨·주관식 키보드와 철자 조립의 영문 키는 이미지·폭·높이·폰트를 공유한다.
행맨의 다음 단어는 속담의 다음 버튼과 같은 54px 높이·이미지·폰트로 하단에 표시한다.
공통 영어 키보드에서 삭제 키를 제외하고 사용한 글자를 잠근다. 짧은 화면은 그림을 줄이고 뜻·키보드·다음 버튼 자리를 유지한다.
다음 단어는 키보드를 다시 표시하며 이전 판 입력은 무시한다.

## 복수 퀘스트

오답의 단어·뜻·몬스터를 단어장별로 저장하고 원본에 없는 항목은 제외한다.
로비·결과에서 목록을 열며 완료 전 영어 정답은 숨긴다.

1. 오답은 `revenge` 상태로 즉시 재도전한다.
2. 복수 정답은 최초 추가 4 G, `recall` 상태로 옮겨 24시간 대기한다.
3. 회상 정답은 최초 추가 8 G, `complete` 상태로 옮긴다.
4. 다시 틀리면 재도전으로 돌아가지만 받은 보너스는 반복하지 않는다.

회상 가능한 항목을 우선해 최대 10문제씩 진행한다. 일반 전투 정답은 퀘스트 완료로 처리하지 않는다.
보너스는 단어·단어장별 한 번이며 장비/보물 길 배율을 적용하지 않는다.

## 장비와 보상

실제 슬롯은 머리·오른손·왼손·양발·장갑이다. 정면 캐릭터의 오른손/오른발은 화면 왼쪽이다.
양손/양발은 각 쌍을 같은 행에 표시하고 별도 무기 슬롯은 없다.

| 위치                | 장비 역할                                                        |
| ------------------- | ---------------------------------------------------------------- |
| 오른손              | 기본 주무기의 3연속 정답 +3 G, 경제 배율, 원소 무기의 고유 효과  |
| 왼손                | 보조 속성/외형, 철제 실드의 전투당 오답 1회 무손실 재시도        |
| 머리                | 헬름의 전투당 무료 힌트 1회                                      |
| 양발                | 부츠 한 켤레의 스토리 안전한 길 +5초 또는 보물 길 기본 보상 +10% |
| 장갑                | 미다스의 건틀릿 장착 중 정답 골드 ×1.5, 정답 10회 후 소모        |
| 슬롯 없는 보유 유물 | 모래시계·수호의 부적·암시장 유물 등 보유 조건 효과               |

플레임텅은 오른손 정답 +2 G, 프로스트 시클은 전투당 오답 1회 재도전, 번개의 스피어는 2연속 정답마다 +3 G를 준다. 원소 무기는 오른손에 장착했을 때만 효과가 발동한다.\n쇼트소드·풍요의 롱소드·황금의 배틀액스는 오른손 전용, 오브·실드는 왼손 전용이다.
그 외 양손 허용 무기는 같은 장착 규칙을 UI·실제 장착·저장 복원에 적용한다.
교체하면 기존 장비는 보관함으로 돌아가며 이미 장착한 슬롯의 버튼은 잠근다. 저장 실패는 이전 상태를 유지한다.
빈 손·빈 슬롯에는 기본 검을 표시하지 않는다. 전투 판정의 기본 무기 fallback은 유지한다.
아바타는 실제 무기·보조 장비·헬름·부츠·건틀릿을 반영하고 해제/소모/새로고침에도 일치한다.

오답/방패 재시도는 콤보를 초기화한다. 방패가 막은 오답도 복습·퀘스트에 남고 첫 시도 골드·통계는 중복 처리하지 않는다.
시간 초과 재시도는 최소 5초다. 헬름은 듣기 완료 전에 소모하지 못한다.
장비·소모품 힌트는 오답 보기를 최소 하나 남기고 한 글자 정답의 추가 철자 힌트는 제공하지 않는다.

보관함은 기본 3칸이며 배낭을 반복 구매하면 한 번에 1칸 늘어난다. 사용량·최대 용량·빈칸과 구매 후 용량을 표시한다.
보관함의 사용 칸 수와 아이콘 목록은 동일한 항목 집합으로 계산하며 암시장 등 슬롯 없는 보유 유물도 목록에 표시한다.
장착 중인 장비·기본 무기·용량 확장·스킬은 보관 칸에서 제외하고 중복 ID는 한 번만 센다.
보관함의 건틀릿은 효과/횟수 차감이 없고 소모 시 슬롯에서도 제거한다.
이전 보유 건틀릿은 장갑 슬롯으로 자동 이전하고 남은 횟수는 최대 10회, 이후 해제 상태는 유지한다.
정답 보상·오답 손실·반올림·시작 골드·전체 가격은 [경제 기준](economy.md)을 따른다.

무기 형태·오른손 속성·왼손 보조 속성·콤보·방패 효과를 구별한다.
효과는 720ms, 다음 문제 전환은 800ms이며 전환/취소/종료 때 늦은 콜백을 차단한다.
캐릭터의 대기·공격·피격은 몸·머리·장비를 포함한 컨테이너 전체에 적용한다.
슬라임은 탄성 점프, 고블린은 경계·돌진, 박쥐는 부유·급강하, 드래곤은 호흡·내려찍기로 구별한다.
문제 진입 때 등장 문구를 짧게 표시하며, 공격·피격이 시작되면 문구를 지운다.
공격 효과음은 즉시 시작하고 타격음·입자·화면 반응은 무기 프로필의 impactMs에 맞춘다.
몬스터 반격은 준비 동작 160ms 뒤 피격음·전체 캐릭터 반동을 적용한다. 보스 오답에도 같다.
결과에는 장착 모습을 복제한 캐릭터의 승리/패배 상태와 승리 시 금화 입자를 표시한다.
스토리 결과의 왕관은 실제 오답 수에 따르며, 일반 도전·총공세에 왕관을 지급한 것처럼 표시하지 않는다.
구매·전리품·장착은 저장 성공 후에만 짧은 알림과 장비 강조를 표시한다. 알림은 버튼 입력을 가로채지 않는다.
진행 저장 후 지도에 돌아오면 새 경로·다음 지점·완료 왕관을 한 번 강조하며 구간별 강조색을 사용한다.
스토리 초기화와 최종 보스 클리어는 진행·선택 경로·이벤트를 비우고 다음 갈림길 구조와 새 이벤트 배치를 함께 저장한다. 저장 실패 시 순서도 넘어가지 않는다. 진행 중인 지도는 새로고침해도 유지한다.
이전 타격·피격 예약은 문제/판 전환 때 무효화하고 화면을 나가면 해당 효과음을 중단한다.
reduced motion에서는 지속 움직임·화면 이동·입자 애니메이션을 끄고 텍스트·완료 상태를 유지한다.

## 화면·음성·설정

게임 효과음은 기본 ON이며 `v7_settings.soundEffects`에 저장한다. 음악·자동 발음과 독립적이다.
사용자 입력으로 Web Audio를 활성화한 뒤 짧은 합성 효과음만 재생하며, 잠긴 브라우저에 음향을 쌓아 두지 않는다.
효과음 OFF·백그라운드·음향 API 미지원/실패에서는 게임 진행을 유지한다. 백그라운드 진입 시 예약 음원을 중단한다.
발음 듣기 문제의 등장 효과음은 생략해 학습 음성을 가리지 않는다.

오답 진동은 영어·사자성어·방패 재시도·보스 실패·행맨·속담·대장간 실패·야바위·총공세 오답/낙하에 공통 적용한다.
진동은 기본 ON이며 설정에서 ON/OFF와 짧게(80ms)/보통(200ms)/길게(350ms)를 저장한다.
기존 설정에는 ON·200ms를 보충하며 진동 미지원·API 오류는 채점을 중단하지 않는다. 길이 설정은 기기의 물리적 진동 강도를 바꾸지 않는다.

게임 프레임 너비는 `min(viewportWidth, appHeight × 3/4)`다. 로비·연습·배틀에 같은 계산을 적용한다.
배경·캐릭터·버튼·패널은 [승인 시안과 독립 이미지 부품](design-assets.md)을 사용하고 문제·값·상태는 HTML이다.
로비 배경과 킹왕짱의 여섯 타이틀 순열은 진입/학습 귀환 시 직전 것을 제외해 고르고 메뉴 열기/닫기에는 유지한다.

모드 버튼은 기준 크기의 88%, 내부 아이콘은 모드 너비의 22%/하단 메뉴 너비의 28%다.
도전은 붉은색이며 보기에는 번호를 붙이지 않는다.
전투 배경은 상단 헤더 뒤까지 이어지고 골드는 범위 옆에서 실제 자릿수에 맞춰 늘어난다.
좁은 화면은 상태 줄을 줄바꿈하며 저장 값을 표시용으로 제한하지 않는다.
철자/입력/공격·듣기 보기·퍼즐 선택지는 하단에 두고 긴 문제는 문제판 안에서 읽는다.
로비 복수는 숫자 없이 아이콘과 ‘복수’를 표시하는 44px 사각형 버튼이다.

native dialog와 공통 전체화면 버튼 하나를 사용한다.
전체화면은 프레임 우상단 시작선 12px·44px이며 가장 위 dialog 안으로 이동해 top layer에서도 조작한다.
전환 후 열린 팝업·입력·스크롤을 복원한다. 내부 메뉴·결과는 우상단 X로 닫고 중복 하단 닫기는 없다.
공통 확인창은 회색 취소/파란 실행/붉은 초기화·경고를 사용하고 스토리 확인은 X 취소와 실행 하나를 둔다.
설정·스토리·게임의 시작/진행/다음/구매도 같은 실행 색상을 사용한다. 공격과 로비 모드의 고유 색은 유지한다.
속담·단어 대장간·야바위의 다시하기는 일반 녹색 버튼을 사용한다.
장착 무기의 연속 공격은 배경·테두리·아이콘 없이 `Combo 숫자` 글자만 표시한다. 숫자는 계속 올리고 3·6·9회처럼 3회마다 보너스를 지급한다. 보너스 지급 후에도 콤보는 초기화하지 않는다.
팝업 실행 버튼의 최소 높이는 54px이며 글자 크기는 프레임 폭 기준 14~19px다. 야바위 진행 버튼은 보기 크기를 유지한다.
닫기 X는 44px 조작 영역·25px 글자를 공유한다. 어두운 팝업의 안내와 항목 이름은 밝게 표시한다.
행맨·속담·대장간도 공통 화면 전환과 브라우저 뒤로 가기를 사용하며 게임 중 로비는 숨기고 비활성화한다.
상점·장비·통계는 같은 높이의 팝업과 제목 아래 전폭 안내 띠를 사용한다. 보관함 현황·현재 단어장은 본문 스크롤 밖의 같은 위치에 표시한다.
팝업 제목·장비 상세 이름은 프레임 폭에 따른 22~32px·굵기 800·줄 높이 1.2다.
제목 패딩은 세로 4px, 제목 아이콘은 40px, 한 줄 제목 영역의 최소 높이는 52px다. 닫기 버튼은 44px 조작 영역을 유지하고 모드 카드 패딩은 세로 12px다.
밝은 입력/select/option은 어두운 글자, 어두운 패널은 크림색 글자다.
도전 라디오 체크는 밝은 금색이며 최초/저장 선택을 복원한다.

설정의 암호·인쇄·골드 편집은 같은 dialog 내부 패널이다.
문제 출력·통계 초기화는 각각 전체 너비 한 줄이다.
음악 OFF→ON을 연속 3회 반복하면 골드 수정·통계 관리와 행맨·총공세·사자성어·야바위·속담·대장간 버튼을 공개한다.
전환 사이 5초 초과·다른 설정 변경·설정 닫기는 해금 입력을 초기화하고 닫으면 다시 잠근다.
기존 관리 암호 확인과 잠긴 게임의 직접 실행 차단을 유지한다.

배경음악은 로컬 MP3 20곡으로 첫 곡은 랜덤·종료 후 순환한다. `preload="none"`을 사용한다.
ON/OFF와 OFF 사선은 실제 재생 상태·자동재생 실패를 반영한다.
‘곡’ 목록 아이콘은 ON/OFF 바로 옆에 두고 선택 이름은 펼친 목록에서 표시한다.
발음은 Web Speech 영어 음성 우선, 실패 시 원격 Google TTS다.
수동 버튼은 아이콘과 ‘다시 듣기’를 사용한다. 발음 중 음악을 멈추고 완료/취소 시 이전 상태로 복원한다.
발음 중 음악 ON/곡 변경은 완료 후 재생하며 전환/나가기/자동 읽기 해제는 음성을 취소한다.
원격 실패는 수동 요청에 안내하고 자동 발음은 알림을 반복하지 않는다. 외부 폰트는 사용하지 않는다.

### 문제 출력

출제 Day는 한 줄에 3개의 Day 번호 칩으로 배치한다. 크림색 배경·숲색 선택 상태·금색 체크와
선명한 둥근 테두리를 사용하며, 전체 Day 이름은 툴팁과 접근성 이름으로 제공한다.
선택 단어장에서 여러 Day를 체크하면 Day 번호순으로 독립된 문제지와 답안지를 만든다.
각 Day의 문항 번호는 1부터 시작하며 제목·문항 수·점수·답안 표도 Day별로 분리한다.
Day는 문제지·답안지 제목에 표시하고 개별 문항에는 반복하지 않는다.
Day별 최대 문항 수는 모든 문제(기본값)/10/20/30문항이며 모든 문제는 30문항 제한 없이 출력한다.
객관식/혼합/주관식을 고르며 중복 제거와 문항 수 제한은 각 Day에 독립적으로 적용한다.
단어·뜻 중복을 제거하고 영어/한국어 방향을 교대로 배치하며 혼합형은 절반을 객관식으로 만든다.
10/20/30문항에서는 영어 단일 단어의 Porter 어간이 같은 활용형·파생형(예: isolation/isolated)을
Day별로 하나만 무작위 출제한다. 제외된 자리는 다른 어간의 단어로 채우며 후보가 부족하면 문항 수가 줄어든다.
모든 문제는 이 어간 중복 제한을 적용하지 않고, 숙어는 전체 표현으로 구별한다.
오답은 같은 Day 우선·부족하면 단어장 전체에서 보충한다.
동일 영단어의 다른 뜻과 겹치는 뜻을 제외하고 Day별 정답 위치 빈도 차이는 1 이하다. 부족한 보기는 주관식으로 바꾼다.

독립 HTML은 흑백 A4 세로·14mm 여백·11pt 본문, 이름/날짜/점수와 주관식 답란을 제공한다.
긴 내용은 줄바꿈·추가 페이지로 이어지고 정답지는 별도 번호·문제·정답 표다.
다운로드/새 창에서 모든 Day 또는 특정 Day와 문제지만·정답지만·둘 다를 선택해 브라우저 인쇄/PDF 저장을 이용한다.
각 Day는 새 페이지에서 시작하므로 따로 생성해 인쇄한 시험지와 같은 구성이다.

## 저장 계약과 제약

PWA는 `manifest.webmanifest`·192/512px 아이콘·`sw.js`로 설치와 오프라인 실행을 제공한다.
설치 앱은 `fullscreen` 모드로 시작한다. 이미 전체화면으로 실행된 앱은 전체화면 버튼을 숨기며, 브라우저에서의 전체화면 요청은 `navigationUI: hide`를 사용한다. OS·브라우저가 전체화면을 지원하는 범위에서 상태바·탐색 UI를 숨긴다. `viewport-fit=cover`로 노치 주변까지 배경을 확장하고 조작부는 safe-area 여백을 유지한다.
설정의 앱 설치는 지원 브라우저의 설치 창을 열며, 미지원/iPhone은 브라우저별 홈 화면 추가 방법을 안내한다.
빌드는 HTML·CSS·JS·데이터·이미지의 해시로 서비스 워커 버전을 만들고 음악을 제외한 런타임을 사전 저장한다.
첫 온라인 캐시 준비 후 학습 화면을 오프라인으로 열 수 있다. 음악은 온라인 전용이며 기존 브라우저별 저장 계약을 유지한다.
문서 탐색은 온라인 응답을 우선하고 오프라인에는 저장한 화면을 연다. 버전이 붙은 에셋은 같은 버전만 사용한다.
앱 시작 주소만 오프라인 화면으로 저장하며 다른 문서/데이터 탐색으로 덮어쓰지 않는다.
캐시 접근이나 저장에 실패해도 정상 온라인 응답은 그대로 사용한다.
새 워커는 기존 게임을 강제로 새로고침하지 않고, 이전 앱 창이 닫힌 뒤 활성화하며 이 앱의 이전 캐시만 정리한다.
연습의 필터·외움·발음·이전/다음 버튼은 최소 높이 60px, 500px 이하 화면은 52px로 세로 여유를 둔다.

`gameStorage`만 localStorage에 접근하고 `database.js`가 검증·레거시 복원·영속화를 소유한다.
상점/암시장 구매, 이벤트 비용/지급과 스토리 진행은 관련 값을 함께 저장한 뒤 메모리·UI에 반영한다.
실패 시 기존 값을 복원하고 지급 재시도는 중복 보상을 막는다.
브라우저 강제 종료나 복원 자체가 차단된 저장소까지 완전한 트랜잭션을 보장하지는 않는다.

| 키                                                                                                      | 내용                              |
| ------------------------------------------------------------------------------------------------------- | --------------------------------- |
| `v7_gold`, `v7_owned`, `v7_equip`, `v7_dura`                                                            | 골드·보유·레거시 주무기·내구도    |
| `v7_inventory`, `v7_equipped`, `v7_inventory_capacity`, `v7_skills`                                     | 보관함·장착·용량·스킬             |
| `v7_stats`, `v7_practice_memorized`, `v7_revenge_quests`                                                | 단어장별 `book-ID` 기록           |
| `v7_settings`, `v7_last_day`, `v7_last_count`, `v7_last_question_type`, `v7_last_battle_type`           | 설정·선택 복원                    |
| `v7_story_stage_book-ID`, `v7_story_path_book-ID`, `v7_story_events_book-ID`, `v7_story_layout_book-ID` | 단계·경로·공개/지급/왕관/Day·배치 |
| `selectedGameDataSet`                                                                                   | 선택 단어장                       |

키·아이템 ID·단어장 ID·화면 ID 변경은 마이그레이션과 동작 테스트가 필요하다.
통계 초기화는 통계만 지우고, 게임 완전 초기화는 확인 후 모든 `v7_*`와 `selectedGameDataSet`을 지운 뒤 새로고침한다.
같은 출처의 게임 외 저장 값은 지우지 않으며 삭제 실패도 먼저 지운 키를 복원한다.

계정/서버 동기화·전체 단어의 장기 간격 반복은 없다. 외움은 자기 평가, 복수는 한 차례 24시간 회상이다.
발음 품질·오프라인 재생·음량은 기기/설치 음성에, 원격 폴백은 네트워크/서비스 가용성에 의존한다.
관리 암호는 로컬 실수 방지용이며 서버 인증이 아니다.
일부 주변 서비스의 전역 결합·큰 CSS cascade가 남고 strict 타입 검사는 연습/발음 경로만 대상으로 한다.
모든 단어에 검토된 예문이 있지는 않아 영어 뜻풀이 폴백을 유지한다.
이 제약은 자동으로 실행할 후속 개발 목록이 아니다.
