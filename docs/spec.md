# 현행 게임 사양

2026-10-08 구현 기준. 개발 원본은 HTML/CSS/JavaScript 정적 앱이며 빌드 없이 실행된다.
`obmaz/fantasyword`는 push 시 GitHub Actions 검증/빌드를 실행하며 배포는 `Deploy Pages` 수동 실행이다.
현재 [dokdok.quest](https://dokdok.quest/)는 이 저장소의 `dist/` artifact를 GitHub Pages로 서비스하며 HTTPS를 강제한다.
개발은 Node.js 22 이상, CI는 24. 서버·계정·런타임 npm 의존성은 없다.

로비의 스토리 모드와 1일 전투 버튼은 승인된 로비 그림체에 맞춘 독립 생성 아이콘을 사용하며 이름은 HTML 텍스트다.
설정의 게임 완전 초기화는 별도 확인 뒤 모든 `v7_*` 저장 값과 `selectedGameDataSet`을 지우고 새로고침한다. 골드·장비·스토리 경로·외움·복수 퀘스트·통계·설정과 선택 단어장이 기본값으로 돌아간다. 같은 출처의 게임 외 저장 값은 지우지 않는다.

## 총공세

로비에서 Day를 고른다. 해당 Day의 모든 단어를 섞어 중복 없이 한 번씩 출제하며 영어 또는 한국어 방향도 무작위로 선택한다. 단어를 누르면 아래에 해당 뜻 또는 영어 보기 최대 4개가 나온다. 제한 시간은 `5초 + 단어 수 × 3초`이며, 정답을 고르면 공격 효과와 6 G를 얻는다. 오답과 바닥에 닿은 단어는 생명을 1개 차감하고 제거한다. 생명 5개를 모두 잃으면 종료하며, 모든 단어를 맞히면 승리한다.
매 판 총공세 도박 효과 하나가 무작위로 적용된다. 기본, 적 등장 가속, 일부 적 하강 가속 중 하나이며 별도 구매가 없다. 총공세 전용 3초 정지 장치는 Day마다 1개씩 기본 지급되는 일회성 아이템이다.
등장 간격은 2.4초에서 최소 0.8초까지, 낙하 속도는 시간에 따라 증가한다. 나가기·결과 버튼은 마을로 돌아가고 진행 중인 단어와 타이머를 정리한다.
프레임 지연과 배경 탭 시간도 총공세 제한 시간에 포함하며 마감 후 제출한 답에는 보상을 주지 않는다. 종료 시 공격 효과와 예약된 정리 작업도 제거한다.
단어를 선택하기 전에는 하단 안내판이 글자 높이만 차지하고, 선택 후에는 보기 네 개를 화면 하단에 표시한다.
총공세 나가기는 다른 게임과 동일한 44px 사각형 이미지에 `나가기` 문구를 표시한다.
연습과 총공세의 상단 조작 영역은 각 모드의 배경 그림이 이어지며, 철자 조합 타일의 글자는 타일 정중앙에 배치한다.
결과창은 기존 생성 이미지 프레임, 양피지 정답/획득 통계칸, 집 아이콘 마을 버튼을 사용한다. 작은 화면에서는 엠블럼과 여백을 줄인다.

## 단어장과 단어 모험

단어장 1번 1,198개/60일, 2번 896개/30일, 3번 330개/11일. 총 2,424개다.
선택 단어장에 맞춰 단어·스토리·Day 목록을 로드한다. 통계와 외움 표시는 `book-ID`별이다.

학습 모드의 표시 이름은 로비·선택창·게임·접근성 안내 모두 `단어 모험`으로 통일한다. 내부 practice ID와 저장 키는 유지한다.
단어 모험은 Day/전체의 영어 카드와 뜻·설명을 바로 보여준다. 뜻 회상 문구와 확인/숨기기 버튼은 표시하지 않는다.
풀이 → 단어 → 뜻 순서로 표시하며 본문을 위해 배경 높이가 먼저 줄어든다. 짧은 화면은 카드·버튼 여백을 줄이고 높이 420px 이하에서는 풀이 아래 단어와 뜻을 나란히 배치한다. 내용이 실제로 넘칠 때만 본문 안에서 스크롤하며 하단 조작은 항상 표시한다.
이전/다음, 영문/한글 설명 전환, 수동/자동 발음, 외움 표시와 전체/외움/미암기 필터를 지원한다.
필터 목록에서 현재 단어가 빠지면 같은 위치의 다음 단어로 진행한다.
결과의 틀린 단어 복습은 이번 판 오답을 중복 없이 모으고 원본 설명을 유지한다.
스토리 결과에서 복습이나 복수 목록으로 이동하면 해당 결과의 지도 복귀 상태를 정리한다.
외움 표시는 자기 평가이며 전체 단어의 장기 숙련도/간격 반복 예약은 없다.

## 1일 전투·스토리와 몬스터

1일 전투는 범위를 고른 뒤 스토리 카드나 경로 선택 없이 바로 시작한다.
스토리 모드는 로비 왼쪽에서 열고 생성 이미지 위의 실제 버튼으로 다섯 지점의 갈림길 지도를 진행한다. 선택 가능한 다음 전투와 암시장 중 한 곳을 고르며 승리 또는 암시장 통과 시 다음 지점이 열린다. 진행도와 선택 경로는 `v7_story_stage_book-ID`, `v7_story_path_book-ID`로 단어장별 저장한다. 암시장의 전용 유물 그림자 나침반(180 G)은 스토리 전투의 시간 제한 문제에 3초를 더하며 일반 상점에는 없다. 구매 성공률은 75%이고 실패해도 180 G를 잃는다. 확률과 손실은 버튼 전에 표시하며 잔액이 있으면 재시도할 수 있다.
지도 배경은 채도·밝기를 낮추고, 전투·암시장·보스 아이콘과 현재 선택 지점의 테두리는 독립된 밝은 이미지로 표시한다. 듣기 문제는 듣기 버튼에 자동 여백을 넣지 않고 보기 위의 남는 공간만 늘려 보기를 하단에 유지한다.

범위는 Day/전체, 문제 수는 10/20/전체다. 새 기본 유형은 `monsters`이며 저장된 기존 유형은 복원한다.
객관식·주관식·혼합형도 유지한다. 혼합형은 가능한 범위에서 두 유형을 번갈아 출제한다.

| 몬스터 | 문제                                    | 시간·입력                         |
| ------ | --------------------------------------- | --------------------------------- |
| 슬라임 | 영어 단어 → 한국어 뜻 선택              | 객관식 제한 시간                  |
| 고블린 | 섞인 글자 조각으로 철자 조립            | 시간 제한 없음; 완성 전 공격 불가 |
| 박쥐   | 발음 듣기 → 한국어 뜻 선택              | 발음 완료 뒤 보기와 시간 활성화   |
| 드래곤 | 검토된 예문의 빈칸, 없으면 영어 뜻 풀이 | 시간 제한 없이 전체 단어 입력     |

일반 몬스터는 섞은 순서로 순환하고 마지막 문제는 드래곤이다.
고블린의 중복 글자는 별도 조각이며 정답에 필요한 글자 외에 흔한 모음·자음 조각 3개를 섞는다. 정답 글자 수를 채우면 제출할 수 있고 나머지 조각은 선택할 수 없다. 숙어의 공백/구두점은 유지하며 지우기·다시 조립·키보드 입력을 지원한다.
방해 글자는 정답에 없는 알파벳으로 고르고 흔한 글자가 부족하면 다른 알파벳으로 보충한다. 드래곤 설명에 정답 단어가 포함되면 그 부분을 빈칸으로 가린다.
드래곤 예문은 단어의 `exampleSentence` 또는 `data/battle-examples.js`를 사용하고 실제 목표 단어가 있을 때만 빈칸으로 만든다.

박쥐는 다시 들어도 시간이 늘지 않는다. 음성 실패/12초 미완료 시 같은 단어의 뜻 문제로 바뀌며 수동 전환도 가능하다. 듣기 문제는 질문 카드에 정답 단어를 표시하지 않는다.
문제 전환/나가기 이후 늦은 음성 콜백은 무시한다. 모든 단어는 브라우저 영어 TTS를 우선 사용하고, 음성 지원이 없거나 재생에 실패하면 원격 TTS를 사용한다. 발음 재생 중 배경음악은 일시정지하고 완료·취소 시 기존 재생 상태로 돌아간다.
몬스터 문제는 대소문자·앞뒤/연속 공백을 정규화한 전체 답으로 채점한다.
기존 주관식은 호환상 전체 철자 또는 맨 앞 한 글자를 제외한 입력도 허용한다.

선택 문제의 기본 시간은 10초, 모래시계 보유 시 15초다. 부츠의 안전한 길은 스토리 전투에서 추가 5초다.
실제 마감 시각을 검사하며 백그라운드 탭에서도 시간이 흐른다. 주관식/조립에는 시간 제한이 없지만 정답 골드는 풀이 시간이 길수록 줄어든다.
선택 문제는 객관식 통계, 조립/입력은 주관식 통계이며 결과에는 몬스터별 학습 방식과 전체 성적을 표시한다.
전체 단어 도전은 단어장 전체를 섞은 유한 덱으로 드래곤 문제를 진행한다.

## 복수 퀘스트

오답은 뜻/단어와 몬스터를 단어장별로 저장한다. 새로고침 후에도 유지되며 원본 단어장에 없는 항목은 목록에서 제외된다.
로비와 결과에서 목록을 열 수 있다. 완료 전에는 뜻을 보여주고 영어 정답은 숨긴다.

1. 오답: `revenge` 상태로 즉시 재도전 가능.
2. 복수 모드에서 정답: 최초 +50 G, `recall`로 이동해 현재 시각부터 24시간 대기.
3. 대기 후 회상 정답: 최초 +100 G, `complete`로 이동.
4. 다시 틀리면 재도전으로 돌아가지만 이미 받은 보상은 반복 지급하지 않는다.

회상 가능 항목을 우선해 최대 10문제씩 진행한다. 일반 전투의 정답은 퀘스트 완료로 처리하지 않는다.
보너스는 단어·단어장별 한 번이며 무기/황금장갑/보물 경로 배율을 적용하지 않는다.
이는 오답에 대한 한 차례 24시간 회상이며 범용 장기 간격 반복 시스템은 아니다.

## 장비와 슬롯

머리·오른손·왼손·양발만 실제 슬롯이다. 정면 캐릭터 기준 오른손/오른발은 화면 왼쪽이다.
양손·양발은 각각 같은 행이며 기본 검은 오른손의 기본 장비다. 별도 무기 슬롯은 없다.

| 위치/조건 | 장비                                                  | 역할                                                             |
| --------- | ----------------------------------------------------- | ---------------------------------------------------------------- |
| 오른손    | 기본 검·검·도적 단검·왕가 검·재벌 도끼·화염/서리/뇌전 | 주무기; 3연속 정답마다 +10 G 추가 공격; 경제 무기의 골드 배율    |
| 왼손      | 검·도적 단검·화염/서리/뇌전·우주 파괴자·방패          | 보조 속성/외형; 방패는 전투당 오답 1회 무손실 재도전             |
| 머리      | 투구                                                  | 전투당 무료 힌트 1회: 오답 보기 제거 또는 정답 일부 철자/글자 수 |
| 양발      | 부츠 한 켤레                                          | 스토리 전투의 안전한 길(시간 +5초) 또는 보물 길(기본 보상 +10%)  |
| 보유 유물 | 모래시계·수호 방패·황금장갑 등                        | 슬롯 없이 보유 조건으로 효과                                     |

왕가의 검·재벌 도끼·기본 검은 오른손 전용, 우주 파괴자·방패는 왼손 전용이다.
장착 가능 손은 `weaponEquipSlots`가 UI·실제 장착·저장 복원에 공통 적용한다. 잘못된 손 요청은 거부한다.
부츠는 양발을 함께 장착한다. 장비는 소유만 하면 장착 능력이 활성화되지 않는다.
오답/방패 재시도는 콤보를 초기화한다. 방패로 막은 오답도 복습/퀘스트에 남고 첫 시도 골드·통계는 중복 처리하지 않는다.
시간 초과 방패 재시도는 최소 5초를 준다. 투구는 박쥐의 듣기가 완료되기 전 소모할 수 없다.
보기 제거 힌트는 오답 보기를 최소 하나 남기며, 한 글자 단어의 철자는 힌트에 표시하지 않는다.

수호 방패 유물은 오답 손실을 100 G에서 50 G로 줄이며 왼손 장착 방패와 별개다.
모래시계는 시간 +5초, 황금장갑은 정답 골드 ×1.5/30회, 가방은 보관함 용량 +1이다.
유료 힌트/필살기는 기존 구매 횟수를 사용한다. 구매는 실제 카탈로그 가격, 중복 제한·보관 용량을 검사한다.

## 보상과 전투 효과

기본 정답 보상은 선택 문제 최대 20 G, 주관식·조립 최대 30 G, 전체 단어 도전 최대 40 G다.
선택 문제는 남은 시간 비율, 시간 제한이 없는 문제는 최대 30초의 풀이 시간에 따라 보상이 최대치에서 25%까지 줄어든다. 문제 수는 문제당 보상을 늘리지 않는다.
오른손 경제 무기 배율과 황금장갑을 적용한 뒤 보물 길·콤보·고정 퀘스트 보너스를 더한다.
3연속 정답의 +10 G는 줄어든 정답 보상에 더하며 화면에는 합계와 내역을 함께 표시한다.
세부 반올림은 `battleRules.reward`와 전투 세션을 기준으로 한다. 오답 손실은 보유 골드를 넘지 않는다.

단검은 이중 찌르기, 검은 베기/교차 베기, 도끼는 내려찍기와 지면 충격이다.
화염 상승 베기·서리 낫 휘두르기·뇌전 찌르기와 독립된 속성 이미지 효과를 사용한다.
왼손 속성이 오른손 무기 모션을 바꾸지 않고 보조 레이어로 겹친다. 콤보는 추가 공격을, 방패는 가드 그림을 표시한다.
효과 종료 720ms, 다음 문제 전환 800ms. 취소/종료/다음 문제에서 늦은 효과가 남지 않는다.
reduced motion에서는 이동/입자 대신 짧은 투명도 변화로 표시한다.

## UI·음성·설정

가로:세로 최대 3:4의 세로 프레임이며 로비·연습·배틀 크기를 함께 계산한다. 짧은 세로 화면에서는 전투 장면과 답안 영역을 압축해 불필요한 내부 스크롤을 줄인다. 철자 조합·주관식 입력과 공격 버튼은 답안 영역 하단에 두고, 짧은 화면에서도 전체화면 버튼이 상단 상태 바 안에 들어오게 한다.
타이틀은 킹왕짱의 6가지 순열, 시작 배경은 숲/노을/달빛 중에서 직전 것을 제외해 선택한다.
시작과 학습에서 제목으로 돌아올 때 바뀌며 메뉴를 여닫을 때는 유지한다.

배틀은 상단의 큰 붉은 버튼, 연습/전체 단어 도전과 하단 내부 메뉴는 독립 생성 이미지 버튼이다.
팝업은 native dialog, 값·문제·입력·가격·통계는 HTML이다. 내부 메뉴는 중복 마을 버튼 없이 우상단 X로 닫고, 전체화면은 항상 게임 프레임 우상단이다. X와 나가기는 전체화면과 같은 사각형 이미지 재질을 쓰며 골드와 독립된 칸에 배치한다. 스토리 지도는 제목 아래 콘텐츠만 스크롤한다.
로비 메뉴 버튼은 원래 크기의 80%로 중심 위치를 유지한다. 객관식 보기에는 번호를 표시하지 않고 채점 후 정답/오답 표시를 유지한다. 닫기가 필요한 팝업에는 우상단 X를 둔다.
단어장 변경과 통계 초기화에 쓰는 확인창은 짙은 패널 위에 밝은 안내 문구를 표시한다.
전투 골드는 범위 표시(전체/Day) 바로 옆 같은 줄이며, 배경 한 장이 상단 메뉴와 전투 영역 뒤로 이어진다.
상단 조작·제목·캐릭터·문제·음악 선택·타이머의 기존 배치는 유지한다.
목록 아이콘과 ‘곡’ 표시의 곡 선택은 모든 높이에서 음악 ON/OFF 바로 앞에 둔다. ON/OFF의 음표 아이콘과 구분하며 선택된 곡 이름은 펼친 목록에서만 표시한다.
설정 내부 암호/인쇄/골드 편집은 패널 전환이다. 문제 출력은 독립 HTML 문제지/정답지이며 보기가 부족하면 주관식으로 대체한다.
출력 문제의 단어·뜻 중복을 먼저 제거하며 긴 보기와 답은 줄바꿈해 전부 표시한다. 내용이 A4 한 장을 넘으면 다음 페이지로 이어진다.
로컬 관리 암호는 실수 방지용이며 서버 인증이 아니다.

배경음악 20곡은 로컬 MP3이며 첫 곡은 랜덤, 종료 후 순환한다. 실제 오디오 재생 상태를 ON/OFF와 사선 아이콘으로 표시한다.
곡 선택 select/option은 밝은 바탕·어두운 글자다. 음악은 `preload="none"`으로 필요할 때 로드한다.
발음은 Web Speech 영어 음성을 우선하고 실패 시 원격 Google TTS로 폴백한다.
첫 자동 발음부터 음악을 일시정지하고, 발음 중 음악 ON/곡 선택은 발음이 끝난 뒤에 재생한다.
취소·전환·나가기·자동 읽기 해제에서 음성을 중지한다. 원격 실패는 수동 발음에 안내하고 자동 발음은 알림을 반복하지 않는다.
원격 폴백과 일부 음성은 네트워크에 의존한다. 외부 폰트는 사용하지 않는다.

## 저장 계약

모든 진행은 브라우저 localStorage에 저장한다. 계정/서버 동기화는 없다.
`gameStorage`가 접근하고 `database.js`가 검증·레거시 장비/단어장 키 복원·영속화를 담당한다.

- `v7_gold`, `v7_owned`, `v7_equip`, `v7_dura`: 골드·보유·주무기·내구도.
- `v7_inventory`, `v7_equipped`, `v7_inventory_capacity`, `v7_skills`: 장비·장착·보관 용량·스킬.
- `v7_stats`, `v7_practice_memorized`, `v7_revenge_quests`: 단어장별 `book-ID` 기록.
- `v7_settings`, `v7_last_day`, `v7_last_count`, `v7_last_question_type`: 설정·선택 복원.

키/아이템 ID/단어장 ID 변경은 마이그레이션과 테스트를 함께 해야 한다.
통계 초기화는 통계 기능이며 브라우저 저장소 전체 삭제로 바꾸지 않는다. 저장 불가 시 알림을 표시하고 게임은 계속한다.
