# 스토리 퍼즐 변경 코드 재검토

2026-10-11. 야바위 난이도 변경, 속담·단어 대장간의 스토리/어드민 통합을 검토했다.

- 세 주사위의 색상과 숫자를 중복 없이 배정해 속성 질문의 정답 컵이 하나다. 주사위는 컵 ID에 묶고 화면 이동은 자리 배열로 표현하므로 애니메이션 뒤 정답과 공개 위치가 일치한다.
- 첫 질문은 섞기 완료 뒤 정하며 두 번째 질문은 다른 주사위/반대 속성이다. 단계와 세션 세대로 섞는 중 입력·지난 질문·이전 판의 콜백을 차단한다. 결과를 다시 공개하기 전에 2배 컵을 고른다.
- 속담 보기는 정답 하나와 고유 오답 세 개다. 단어 대장간은 검토된 초급 단어 풀에서 한 글자 교환을 판정하고 BFS로 최단 거리와 해답 존재를 검증한다. 같은 단어·풀 밖 단어·두 글자 교환은 받지 않는다.
- 세 번째 속담 오답/대장간 변환 소진은 실패한다. 정답 후 다음과 저장 재시도는 단계로 제한하고 문제 세대가 이전 버튼 콜백을 막는다.
- 스토리는 입장 확인 뒤 실행한다. ?의 새 결과는 기존 공개 비용과 저장 고정을 유지한다. 직접 지점/재배치 지도에도 새 퍼즐을 넣는다. 두 퍼즐을 비전투로 분류해 다른 퍼즐·암시장·상자·도박장·?와 연속으로 연결하지 않고 각 지점의 진입/출구도 검사한다.
- 퍼즐 보상과 왕관·단계·경로는 함께 저장한다. 저장 실패 시 모두 보존하고 재시도 성공 후 중복 보상을 막는다. 지난 단어장 결과는 받지 않는다. 실패/중도 종료는 같은 지점으로 복귀한다.
- 어드민 두 버튼도 음악 OFF→ON 3회 해금/설정 닫기 재잠금으로 보호한다. 골드·단어장 통계·장비 사용 횟수는 바꾸지 않는다. 공통 헤더·음악·전체화면·이미지 답 버튼을 재사용한다.

검증: `npm run check`의 256개 테스트가 실패/스킵 없이 통과했으며 타입·포맷·등록/에셋 검사도 통과했다. `npm run build`는 232개 런타임 파일을 생성했다.

실제 Chromium에서 390×844, 320×427, 768×1024, 844×390의 어드민 6개 버튼·두 퍼즐 완료·야바위 3개 주사위와 이동/2배 도전·스토리 중도 복귀를 확인했다. 320×427와 844×390에서는 모든 70개 단어의 이웃 보기와 30개 속담을 추가로 렌더링해 답 버튼이 화면 안에 있고 위쪽 내용도 스크롤 없이 들어오는지 확인했다. 전체화면 전환 뒤 퍼즐 유지도 확인했다. 초기 점검에서 가로 화면의 3줄 선택지가 밀리는 결함을 발견해 문제 본문과 하단 선택 영역을 분리하고 짧은 화면 간격을 줄인 뒤 재검증했다.
