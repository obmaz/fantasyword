# 킹왕짱 RPG — Fantasy Word Game

영단어 학습을 몬스터 전투와 장비 수집으로 이어가는 모바일 중심 정적 웹게임입니다.
HTML/CSS/JavaScript로 동작하며 서버·계정·런타임 npm 의존성이 없습니다.

**서비스:** [dokdok.quest](https://dokdok.quest/) · **저장소:** [obmaz/fantasyword](https://github.com/obmaz/fantasyword)

## 현재 기능

시작 모드는 **스토리·도전·연습** 한 줄 버튼입니다. 전체 단어 도전은 도전 설정의 전투 유형에서 선택하며, 고른 문제 유형으로 단어장 전체를 풀고 첫 오답·시간 초과에 종료됩니다. 방패 재시도는 적용하지 않습니다.

- 연습: Day/전체 단어, 풀이 → 단어 → 뜻 순서로 즉시 표시, 발음, 외움 표시와 필터, 전투 오답 복습. 본문 공간을 먼저 확보하고 배경과 여백을 줄여 스크롤을 최소화합니다.
- 도전: 일반 전투는 Day 범위와 문제 수를 고릅니다. 슬라임은 뜻 고르기, 고블린은 정답 글자 외에 방해 글자 3개가 있는 철자 조립, 박쥐는 발음을 듣고 한국어 뜻 고르기, 드래곤은 문장 빈칸/뜻 풀이입니다. 객관식·주관식·혼합형도 지원하며 전체 단어 도전에서도 문제 유형을 고를 수 있습니다.
- 총공세: 선택한 Day의 모든 단어가 무작위 순서로 한 번씩 등장합니다. 오답과 바닥에 닿은 단어는 생명을 1개 차감합니다. 제한 시간은 5초 + 단어 수 × 3초이며, 매 판 하나의 도박 효과와 3초 정지 장치를 기본으로 받습니다.
- 스토리: 밝은 양피지 지도에 15단계·31개 지점을 표시하고 1~3갈래 경로를 연결합니다. 전투·고정 뜻/철자/듣기·암시장·상자·총공세·미니보스와 ‘?’ 지점이 섞입니다. Day 대신 단어장 전체에서 짧게 출제하며 진행과 물음표 결과는 단어장별로 저장됩니다. 암시장의 그림자 나침반은 스토리 전투의 제한 시간을 늘리며 구매 성공률은 75%입니다. 실패해도 180 G가 차감됩니다.
- 전체 단어 도전: 선택 단어장의 모든 단어를 섞은 유한 덱으로 도전합니다.
- 복수 퀘스트: 틀린 단어를 저장하고 재도전 → 24시간 뒤 회상으로 이어갑니다. 최초 재도전 +50 G, 최초 회상 +100 G는 단어별 한 번만 받습니다.
- 장비: 오른손 주무기의 3연속 정답 보너스, 왼손 방패의 재도전, 투구의 무료 힌트, 스토리 전투에서 부츠의 경로 선택. 별도 장갑 슬롯의 황금장갑은 장착 중 정답 골드 ×1.5, 30회 후 소모됩니다. 무기 형태와 속성별로 전투 모션·생성 이미지 효과가 다릅니다.
- 상점·통계·설정: 실제 가격/수량/성적, 배경음악 20곡, 자동 발음, 골드 편집, 통계 초기화, 독립 HTML 문제지 출력. 문제 출력은 10·20·30문항과 객관식/혼합/주관식을 선택하며, A4 문제지와 교사용 정답지를 따로 인쇄하거나 PDF로 저장할 수 있습니다.
- 설정의 게임 완전 초기화는 확인 후 골드·아이템·장비·스토리 진행·외움·복수 퀘스트·통계·설정을 모두 지우고 다시 시작합니다.
- 설정의 골드 수정은 −/+ 버튼으로 조정하며 좁은 화면에서도 숫자와 버튼이 겹치지 않습니다. 긴 설정 목록은 내부에서 스크롤합니다.
- 단어장 3개, 총 2,424개 항목. 진행은 현재 브라우저의 localStorage에 저장합니다.

전투 힌트는 정답 보기를 하나만 남기지 않습니다. 정답 골드는 문제 수와 무관하며 답을 늦게 낼수록 줄어듭니다. 3연속 정답의 +10 G는 기본 보상에 더해지고 내역이 표시됩니다.
모든 단어의 발음은 브라우저 영어 TTS로 읽고, 재생할 수 없을 때 원격 TTS로 전환합니다. 발음 재생 중에는 배경음악이 잠시 멈추고 발음이 끝나면 이전 상태로 돌아갑니다. 로비를 터치하면 장착 무기의 이펙트가 표시됩니다.
단어 모험의 수동 발음 버튼에는 음표 아이콘과 ‘다시 듣기’를 표시합니다. 기존 황금장갑은 남은 사용 횟수를 보존해 장갑 슬롯으로 자동 이전합니다.
단어 모험의 카드 크기는 화면 높이에 따라 연속적으로 조절하며, 주소창 높이가 바뀌어도 하단 이동 버튼을 화면 안에 유지합니다.
주관식은 게임 내 QWERTY 키보드(A–Z와 백스페이스)로 입력하며 밑줄 칸에 글자가 채워집니다. 기기 키보드는 열지 않고, 숙어의 공백·구두점은 자동으로 넣습니다. 물리 키보드의 영어·삭제·Enter 입력도 지원합니다. 캐릭터·문제판·키·공격 버튼은 승인된 숲 모험 시안의 생성 이미지 부품을 사용합니다.
총공세는 단어 선택 전에도 보기 영역을 확보해 배경 크기를 유지하고, 생명을 잃는 도착선을 표시합니다.
골드 표시는 실제 자릿수에 맞춰 영역이 늘어나며, 0일 때 불필요한 숫자 공간을 예약하지 않습니다.
문제판은 뜻 글자의 높이를 확보해 잘림을 방지하며, 긴 뜻은 줄바꿈하고 긴 설명은 문제판 안에서 스크롤해 읽습니다.
전투 골드는 범위 표시 옆 같은 줄에 있고, 배경은 상단 메뉴 뒤까지 이어집니다.
목록 아이콘과 ‘곡’ 표시의 곡 선택은 음악 ON/OFF 바로 옆에 있습니다. 메뉴 닫기와 게임 나가기는 전체화면과 같은 사각형 이미지 버튼이며, 내부 메뉴는 중복 마을 버튼 없이 우상단 X로 닫습니다. 지도는 제목 아래 콘텐츠만 스크롤합니다.

장비 메뉴와 전투·총공세 결과도 하단 마을 버튼 없이 우상단 X로 닫습니다. 결과의 복습·복수 퀘스트 버튼은 유지합니다.
스토리 지도·암시장·상자 팝업도 다른 메뉴와 같은 생성 이미지 프레임과 초록 재질을 쓰며, 제목 아래 본문만 스크롤합니다.
로비 우상단 복수 바로가기는 숫자 없이 전용 검·회전 화살표 아이콘과 ‘복수’ 글자를 표시하며, 전체화면과 같은 44px 사각형 버튼입니다.
암시장 하단은 같은 크기의 ‘나가기 / 구매’ 버튼입니다. 스토리 클리어 지점에는 테두리가 표시되고, 새 전투의 오답이 0·1·2개이면 작은 금·은·동 왕관을 표시합니다. 기존 클리어 기록에는 테두리만 표시합니다.
스토리 지도는 차분한 생성 배경 위에 실제 경로를 표시하고, 갈 수 없는 지점은 딤 처리하며 선택을 막습니다. ‘?’는 클릭만으로 정체를 공개하지 않습니다. 무료로 들어가거나 100 G로 먼저 확인할 수 있고, 한 번 확인한 지점은 다시 비용을 내지 않습니다.
철자 조합과 주관식 입력·공격 버튼은 화면 아래에 배치됩니다. 총공세는 보기를 고르기 전 하단 안내판을 줄여 공터를 넓게 보여줍니다.
철자 조합 선택지는 알파벳순이며, 한 줄에 들어가지 않으면 균등한 두 줄로 표시합니다.
듣기 문제의 보기도 하단에 붙고, 여유 공간은 듣기 버튼과 보기 사이에서만 조정합니다. 총공세 나가기는 다른 게임과 같은 44px 사각형 버튼입니다. 스토리 지도 배경은 차분하게 낮추고 전투·암시장·보스 선택 아이콘은 밝게 구분합니다.
단어장 변경·통계 초기화 확인창은 어두운 패널 위에 밝은 안내 문구를 표시합니다.
모드 선택창의 출제/학습 범위·문제 수·문제 유형 제목은 밝은 크림색으로 통일하고, 단어 모험의 설명 전환 안내도 밝게 표시합니다.
로비 버튼 영역은 이전 80% 표시보다 10% 크게(기준 크기의 88%) 표시하고 내부 아이콘은 별도로 줄여 여유를 확보합니다. 답안 선택지에는 번호를 붙이지 않습니다. 팝업의 닫기는 우상단 X를 사용하며 전체화면 전환 후에도 열린 팝업과 입력을 유지합니다. 총공세 결과는 이미지 프레임·양피지 통계칸·마을 버튼으로 통일했습니다.

## 개발과 검증

Node.js 22 이상, npm을 사용합니다. CI는 Node.js 24입니다.

```sh
npm ci
npm run check
npm run build
```

`check`는 JavaScript 문법, 로드 등록·에셋·책임 경계·문서 링크, 연습/발음의 strict 타입 검사,
회귀 테스트와 Prettier 포맷을 검사합니다. `npm run format`으로 코드·문서를 포맷합니다.

원본 `index.html`은 빌드 없이 실행할 수 있습니다. 브라우저 검증에는 정적 HTTP 서버를 사용하세요.
Python이 설치되어 있다면 저장소 루트에서 다음 명령으로 배포 결과를 확인할 수 있습니다.

```sh
python3 -m http.server 8000 --directory dist
```

`dist/`는 재생성 가능한 배포 결과이며 커밋하지 않습니다.
`obmaz/fantasyword`의 GitHub Pages가 `dokdok.quest`를 서비스하며 HTTPS를 강제합니다.
`Validate`는 push 시 검증·빌드를 수행하고, `Deploy Pages`는 수동 실행합니다.
푸시한 `main`을 배포하려면 `gh workflow run pages.yml --repo obmaz/fantasyword --ref main`을 실행하세요.
`build-manifest.json`의 SHA-256과 공개 응답을 비교하면 실제 배포 반영을 확인할 수 있습니다.

최근 [전체 코드 리뷰](docs/review-2026-10-09.md)에서 총공세 시간·아이템·입력 판정, 주관식 채점, 구매/스토리 저장 실패, 초기화와 키보드 접근성의 결함을 수정하고 재검증했습니다.

[경제 기준](docs/economy.md)에 따라 기본 장비의 10문제 전투 수입은 약 50~75 G(정답률 80%·4초 풀이)이며, 초급 무기는 60~120 G, 주요 장비는 180~300 G입니다. D&D 분위기의 장비 이름을 사용하고, 실제 장착한 손 장비·헬름·부츠·건틀릿을 장비 메뉴와 전투 아바타에 반영합니다. 헬름은 머리에 맞춘 착용 그림을 쓰며, 이름이 다른 무기는 고유한 형태와 손잡이 위치로 주먹에 맞춰 표시합니다. 기존 골드·장비·남은 횟수는 보존합니다.

## 제약

계정 동기화는 없으며 기존 `v7_*` 저장 키와 `book-ID` 기록을 유지합니다.
외움 표시는 자기 평가입니다. 복수 퀘스트에 24시간 회상은 있지만 전체 단어의 장기 간격 반복 시스템은 아닙니다.
브라우저 TTS의 음량 상한은 기기와 브라우저에 따릅니다. 브라우저 음성이 실패하면 Google TTS를 사용하며 원격 서비스의 연결 상태에 영향을 받습니다.
폰트는 시스템 폰트입니다. 로컬 관리 암호는 실수 방지용이며 서버 인증이 아닙니다.
package metadata에 선언된 라이선스는 ISC입니다.
