# 킹왕짱 RPG — Fantasy Word Game

영단어를 익히며 몬스터와 싸우고 장비를 모으는 모바일 중심 정적 웹게임입니다.
HTML/CSS/JavaScript로 실행하며 서버·계정·런타임 npm 의존성이 없습니다.

**[게임 플레이](https://dokdok.quest/)** · [GitHub 저장소](https://github.com/obmaz/fantasyword)

## 게임 소개

시작 화면에서 **스토리·도전·연습**을 선택합니다.

| 모드   | 하는 일                                                                           |
| ------ | --------------------------------------------------------------------------------- |
| 스토리 | 15단계 갈림길 지도에서 전투·암시장·상자·총공세·야바위·학습 퍼즐을 진행합니다.     |
| 도전   | Day/전체 범위의 일반 전투 또는 단어장 전체를 한 번씩 푸는 생존 도전을 선택합니다. |
| 연습   | 단어·뜻·풀이를 바로 보고 발음, 외움 표시, 필터와 오답 복습을 이용합니다.          |

몬스터별로 뜻 고르기·철자 조립·발음 듣기·문장 빈칸/풀이 문제가 나옵니다.
철자 조립·주관식은 각 단어의 첫 글자를 고정하고, 영어 뜻만 나오는 7글자 이상 문제는 끝 글자도 제공합니다.
게임 내 영어 키보드와 물리 키보드를 지원합니다.
사자성어는 영어 단어장과 분리된 난이도 1~4에 각 60개씩 총 240개이며, 해당 난이도에서 한 판에 5문제를 출제합니다.

상점에서 산 무기·방패·헬름·부츠·건틀릿은 전투 능력과 착용 모습에 반영됩니다.
장착 무기의 연속 정답에는 콤보 보너스가 있으며, 틀린 단어는 복수 퀘스트로 다시 풀고 24시간 뒤 회상할 수 있습니다.
스토리 지도는 세 갈림길 구조를 순서대로 사용하며, 진행 중인 지도는 저장됩니다.

설정에서 배경음악 20곡, 자동 발음, 게임 효과음과 오답 진동을 조절할 수 있습니다.
문제 출력은 여러 Day를 선택해 독립 HTML 문제지·정답지를 미리 보고, A4 인쇄 / PDF 저장 또는 HTML 다운로드로 보관합니다.
10/20/30문항에서는 같은 어간의 활용형·파생형 중 하나만 출제하며, 모든 문제를 고르면 문항 수 제한 없이 출력합니다.

설정의 **앱 설치**로 PWA를 설치할 수 있습니다. iPhone은 Safari 공유 메뉴의 **홈 화면에 추가**를 사용합니다.
첫 온라인 준비가 끝나면 음악을 제외한 기본 학습 화면을 오프라인에서도 열 수 있습니다.
설치 앱의 상태바와 노치 주변 배경은 기기·브라우저가 허용하는 범위에서 표시됩니다.

단어장 4개에 총 **4,019개 항목**이 있습니다. 능률보카 고등 기본 (2025개정)은 Day 1~40을 지원합니다.
진행은 현재 브라우저의 localStorage에 저장되며 계정 동기화는 없습니다.
설정·외움·장비·스킬·보상은 저장 성공 후 반영하며, 이전 버전 장비와 단어 철자 정정 전 학습 기록도 복원합니다.
발음은 브라우저 영어 TTS를 우선 사용하고 원격 TTS를 폴백으로 사용하므로 기기·네트워크에 따라 차이가 있습니다.
게임 규칙·화면별 배치·저장 계약은 [현행 사양](docs/spec.md), 보상·가격은 [경제 기준](docs/economy.md)을 참고하세요.

## 실행과 검증

원본 `index.html`은 빌드 없이 직접 열 수 있습니다.
개발·검증에는 **Node.js 22 이상**과 npm을 사용하며 CI는 Node.js 24입니다.

```sh
npm ci
npm run check
npm run build
```

`check`는 문법, 로드 등록·에셋·책임 경계, 문서 링크·제목 앵커, 연습/발음의 strict 타입,
동작 테스트와 Prettier 포맷을 검사합니다. 포맷 수정은 `npm run format`입니다.

빌드 결과를 HTTP로 확인하려면 Python이 설치된 환경에서 다음을 실행합니다.

```sh
python -m http.server 8000 --directory dist
```

`http://localhost:8000/`에서 확인할 수 있습니다. `dist/`는 재생성되는 배포 결과이며 커밋하지 않습니다.

## 배포

`obmaz/fantasyword`의 GitHub Pages가 `dokdok.quest`를 서비스합니다.
push 시 `Validate`가 실행되며 `Deploy Pages`는 수동 실행입니다.
검증된 HEAD를 `main`에 푸시하고 해당 SHA의 검증 성공 후 배포합니다.
[실행 명령과 서비스 해시 확인](docs/handoff.md#푸시와-배포)을 따릅니다.
문서·시안·도구·테스트·npm 파일은 배포에 포함되지 않습니다.

패키지 메타데이터에 선언된 라이선스는 ISC입니다.
